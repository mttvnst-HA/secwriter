# Sub-PR 1i — Legacy Editor Retirement Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Retire the legacy contentEditable code path. Collapse SecWriter to a single PM-based editor.

**Architecture:** Three sequential PRs landing over ~1 week. Phase 1 (1i-a) makes CI safe for the cut by promoting the chromium-PM project to the gate. Phase 2 (1i-b.1) does the runtime rewire — origin flip, migrationPartial banner, comment-reconcile undo gate, greptest — without removing any legacy code. Phase 3 (1i-b.2) lands the deletion sweep one day after 1i-b.1 bakes. Phase 4 (1i-c) is deferred to a future PR and out of scope here.

**Tech Stack:** React 18, Vite, Yjs 13, y-prosemirror 1.x, ProseMirror, Vitest, Playwright, GitHub Actions on Windows.

**Spec:** [docs/superpowers/specs/2026-05-16-sub-pr-1i-design.md](../specs/2026-05-16-sub-pr-1i-design.md)

## Working agreements

**Branch model:** Each phase is its own PR off `main` (`feat/1i-a-ci-prep`, `feat/1i-b1-runtime-rewire`, `feat/1i-b2-deletion-sweep`). Do not stack — 1i-b.1 must merge to main and bake one calendar day before 1i-b.2 opens.

**Commit cadence:** One commit per task (a task is a coherent unit, typically a test + implementation). Use conventional commit prefixes (`feat`, `fix`, `refactor`, `test`, `docs`, `chore`). The `co-Authored-By: Claude` trailer is REQUIRED by repo convention.

**Test gates per phase:**
- 1i-a: full `npm test` + `npm run test:server` + `npm run test:compliance` + `npm run test:corpus`. For E2E, the LAST PR commit (CI switch) gates on `--project=chromium` only; earlier commits during the audit still cross-check both `--project=chromium-legacy` AND `--project=chromium` locally to confirm no regressions.
- 1i-b.1: `--project=chromium` is the gate. `chromium-legacy` still exists in playwright.config.js as a local-only safety net.
- 1i-b.2: `--project=chromium` only. `chromium-legacy` is deleted in Task b2.2.

**Never use `replace_all` for indented code** (per CLAUDE.md testing rule #1). Always use unique-context Edits.

**On hook/test failure, do NOT use `--no-verify`** — investigate root cause.

**Rollback procedure (per phase):**
- 1i-a: revert with `git revert <merge-commit>`. Touches only CI config + audit docs; no risk to in-flight work.
- 1i-b.1: clean revert with `git revert <merge-commit>`. Touches `collab.js` origin, App.jsx (TC state + reconcile mirror), PmEditableBlock (banner), block-html-store.js (silent variant), greptest. None of those files have heavy in-flight work in adjacent PRs at the time of writing — verify with `git log --since=...` before reverting.
- 1i-b.2: deletion sweep. A clean revert restores legacy files and resurrects deleted tests. Forward-fix is preferable for small bugs; revert is preferable for systemic breakage. Decide based on the regression's blast radius.

**Bake-day watch criteria for 1i-b.1 → 1i-b.2:**
- Production Sentry/error-reporting count steady (no spike attributable to 1i-b.1's commit hash)
- Zero new GitHub issues tagged with the `comment` / `undo` / `migration` keywords in 24h
- Manual smoke checklist run by the deploying engineer: word-grain Ctrl+Z in and out of room, slash-convert undo, comment-create undo, migrationPartial banner rendering. Document results in the 1i-b.2 PR description.
- If ANY of these signal an unresolved regression, hold 1i-b.2 and forward-fix on `main` first.

import { describe, it, expect } from 'vitest';
import * as Y from 'yjs';
import { ySyncPluginKey } from 'y-prosemirror';
import { seedBlockArray, getBlockHtml } from '../block-html-store.js';
import { applyBlocksToYDoc } from '../collab.js';

function makeSubstrate(initial) {
  const ydoc = new Y.Doc();
  const yOrder = ydoc.getArray('order');
  const yStore = ydoc.getMap('store');
  seedBlockArray(ydoc, yOrder, yStore, initial);
  const undoManager = new Y.UndoManager([yOrder, yStore], {
    trackedOrigins: new Set(['local-publish', ySyncPluginKey]),
    captureTimeout: 500,
    captureTransaction: tr => tr.meta.get('addToHistory') !== false,
  });
  return { ydoc, yOrder, yStore, undoManager };
}

describe('structural undo via applyBlocksToYDoc origin', () => {
  it('out-of-room slash-convert: type change is undoable in one frame', () => {
    const s = makeSubstrate([{ id: 'n1', type: 'txt', html: 'hello' }]);
    // Simulate App.jsx slash-convert: setBlocks → applyBlocksToYDoc.
    applyBlocksToYDoc(s.ydoc, s.yOrder, s.yStore, [
      { id: 'n1', type: 'note', html: 'hello' },

    expect(s.yStore.get('n1').get('type')).toBe('note');
    expect(s.undoManager.undoStack.length).toBe(1);
    s.undoManager.undo();
    expect(s.yStore.get('n1').get('type')).toBe('txt');
  });
});

/**
 * 1i-b.1 — non-tracked-origin variant of setBlockHtml for mechanical
 * substrate mirrors (comment-status reclassify, orphan span unwrap)
 * that must NOT enter the local UndoManager. The Yjs op still
 * broadcasts to peers (origin doesn't gate replication), but Ctrl+Z
 * after the mirror fires will revert the underlying user action in
 * one stroke rather than undoing the mirror.
 *
 * Same shape rules as setBlockHtml: Y.XmlFragment slots go through
 * htmlToPmFragment + prosemirrorToYXmlFragment; Y.Text slots
 * (migrationPartial leftover) go through applyHtmlToYText. Only the
 * transaction origin differs.
 */
export function setBlockHtmlSilent(yStore, blockId, html) {
  const yMap = yStore.get(blockId);
  if (!yMap) return;
  const yHtml = yMap.get('html');
  if (!yHtml) return;
  const ydoc = yStore.doc;
  if (!ydoc) return;
  const next = typeof html === 'string' ? html : '';

  if (typeof yHtml.toArray === 'function' && typeof yHtml.nodeName !== 'string') {
    ydoc.transact(() => {
      const pmNode = htmlToPmFragment(next);
      prosemirrorToYXmlFragment(pmNode, yHtml);
    }, 'local-reconcile');
    return;
  }

  if (typeof yHtml.toDelta === 'function') {
    ydoc.transact(() => {
      applyHtmlToYText(yHtml, next);
    }, 'local-reconcile');
    return;
  }
}

import { describe, it, expect } from 'vitest';
import { readFileSync, readdirSync, statSync } from 'fs';
import { join, relative } from 'path';

const SRC = join(process.cwd(), 'src');
// Allow the literal pattern inside the registry itself + the registry's
// own tests + the inline whitelist marker `/* allowed: block-registry fallback */`.
// Catches single quote, double quote, and backtick (template literal) forms.
const FORBIDDEN = /querySelector\(['"`]\[data-block-id/;
const WHITELIST_MARKER = /\/\* allowed: block-registry fallback \*\//;
const ALLOWED_FILES = new Set([
  'lib/block-registry.js',
]);

function walk(dir, files = []) {
  for (const name of readdirSync(dir)) {
    const full = join(dir, name);
    const st = statSync(full);
    if (st.isDirectory()) {
      if (name === '__tests__') continue;
      walk(full, files);
    } else if (st.isFile() && /\.(js|jsx)$/.test(name)) {
      files.push(full);
    }
  }
  return files;
}

describe('block-registry discipline', () => {
  it('no src/ file outside block-registry.js calls querySelector on [data-block-id] without the whitelist marker', () => {
    const offenders = [];
    for (const full of walk(SRC)) {
      const rel = relative(SRC, full).replace(/\\/g, '/');
      if (ALLOWED_FILES.has(rel)) continue;
      const text = readFileSync(full, 'utf8');
      const lines = text.split('\n');
      lines.forEach((line, idx) => {
        if (FORBIDDEN.test(line) && !WHITELIST_MARKER.test(line)) {
          offenders.push(`${rel}:${idx + 1}  ${line.trim()}`);
        }
      });
    }
    expect(offenders, `Forbidden querySelector pattern. Route through block-registry.js or add inline marker:\n${offenders.join('\n')}`).toEqual([]);
  });
});
