# Corpus Results

Outputs of the SecWriter corpus benchmark suite. Files in this directory are regenerated by `npm run test:corpus && node tools/generate-report.mjs`.

## Files

- **REPORT.md** — human-readable summary across all corpora.
- **metrics.json** — machine-readable per-rule precision/recall plus aggregates.
- **calibration-results.json** / **clean-results.json** / **dirty-results.json** / **adversarial-results.json** — raw findings from each corpus run.
- **rule-id-mapping.json** — semantic injection IDs → engine rule IDs. The dirty-corpus recall analysis is computed against the mapped IDs.
- **ai-results.json** *(optional)* — appended to by `tools/run-ai-corpus.mjs` when an `ANTHROPIC_API_KEY` is provided. Drives the Value (C²/$) section.

## Value (C²/$) metric

```
Value (C²/$) = avg_correctness² ÷ avg_USD_per_run
```

Squaring punishes "cheap but unreliable" models — a model with 0.5 correctness scores 4× lower than one at 1.0 correctness, at the same cost. The framework is adapted from [WriterAgent](https://github.com/KeithCu/writeragent); SecWriter's implementation is plumbing only.

**Correctness** for the AI tier is defined as the fraction of static-engine violations eliminated by the rewrite:

```
correctness_block = 1 - (violations_after / violations_before)
```

Computed by re-running `runStaticRules` over the AI's proposed text. This is a proxy — a rewrite that strips violations but also breaks the semantics scores high. Sentence-level human evaluation is a future follow-up.

**Average USD per run** is computed from the captured `inputTokens` / `outputTokens` per block × the rates in `tools/model-pricing.json`. Cache prices are not modeled; corpus runs don't benefit from prompt caching enough to matter at this granularity.

## Scope: metric only, no policy

This metric **does not** decide which model the panel uses. Model defaults in `src/lib/compliance-ai.js` remain hardcoded; deciding whether to switch the default based on the C²/$ ranking is a separate ticket that has to weigh latency, vendor lock-in, key handling, and rollout. See [#137](https://github.com/mttvnst-HA/secwriter/issues/137) for the original scope statement.

## Capturing data

```bash
# Run the local engines (static, NLP, Harper grammar) over each corpus.
npm run test:corpus

# Run the AI tier — costs real money. Start small.
ANTHROPIC_API_KEY=sk-... node tools/run-ai-corpus.mjs --model claude-haiku-4-5 --limit 5
ANTHROPIC_API_KEY=sk-... node tools/run-ai-corpus.mjs --model claude-sonnet-4-6 --limit 5

# Regenerate REPORT.md + metrics.json with the new AI section.
node tools/generate-report.mjs
```
