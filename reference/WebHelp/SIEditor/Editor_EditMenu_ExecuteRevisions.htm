This command can also be executed by using the keyboard shortcut Ctrl+F8.

The Execute Revisions command finalizes edits by removing all RevisionsThe Revisions command reveals or conceals Revisions that are tagged in the text. Text to be added is identified with underscoring and the addition tags, <ADD> and </ADD>. Whereas text to be deleted, or Redlined, is identified with overstriking and the delete tags, <DEL> and </DEL>, including the ADD tags. This incorporates added text into the Section and permanently deletes all redlined text. 

Always backup the Job before Executing Revisions. Revisions should only be executed on the final submission. Please note these changes are irreversible and cannot be undone using the Undo command.

Revisions may also be executed on the entire Job or individual Sections from the SpecsIntact Explorer's File menu, Right-click menu, or the Sections menu.

How To Use This Feature

to Execute Revisions In A Section:

  1. In the SI Editor, perform one of the following:
    1. Select the Edit menu and select Execute Revisions
    2. Use the keyboard shortcut Ctrl+F8
  2. When the confirmation window opens, click Yes
