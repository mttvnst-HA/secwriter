The Font command is used to modify the font type, size, and style of text that is connected to a specific tag.

Use this function with caution! Modifying the font will globally impact all SpecsIntact files for all JobsA collection of projects and MastersA collection of Masters consisting of the Unified Facility Guides Specifications (UFGS), local agency or company Masters. These changes will persist until the fonts are reset using the Default All button or until the software is reinstalled. Please note that headers and footers are hard coded as Courier New 10 and cannot be altered through these settings.

Tag

Use the Name field to select the name of the tag to format. The corresponding tag will be displayed to the right within the Tag field.

Font

Select the font type, size, and style to be used for the displayed tag. 

  • Face: A list of fonts that can be applied to the selected tag and used to display text within the Section (e.g., Arial, Times New Roman, Calibri, Segoe UI, etc.).
  • Size: A list of font sizes that can be applied to the selected font face.
  • Foreground Color: Used to add a foreground color for the text identified by the specified tag.
  • Background Color: Used to add a background color for the text identified by the specified tag.

If a font type or size is inherited, it indicates the selected tag inherits the font settings from its parent tags. The foreground and background colors are not standard elements used in UFGS Master specifications.

  • Styles: Specific variations in the appearance of a typeface,  such as bold, underline, italic, strike-through, subscript, or superscript.
  • Attributes: Specifies when the fonts are inherited or persistent. The unchecked font follows the font style of the containing tag and the checked fonts are persistent and force their font style on any contained tag.

If you want to give individual occurrences of text the following attributes, use the corresponding tag: Bold, Italic, Center, Underline, Superscript, and Subscript.

Button Functionality

  • Default: Reverts the font settings to the default values specified for the selected tag and restores the inherited font relationships.
  • Default All: Returns all tags to the SpecsIntact default fonts.

Standard Windows Commands

The OK button will execute and save the selections made.

The Cancel button will close the window without recording any selections or changes entered.

The Help button will open the Help Topic for this window.

How To Use This Feature

To Change Fonts:

  1. In the SI Editor, perform one of the following:
    1. Select the Format menu and select Font
    2. Use the keyboard shortcut Alt+C
  2. In the Fonts window, select the Tag Name
  3. Below Font, select the desired font Face, Size, or Style
  4. Click OK

To Reset Fonts:

  1. In the SI Editor, perform one of the following:
    1. Select the Format menu and select Font
    2. Use the keyboard shortcut Alt+C
  2. In the Fonts window, click the Default All button
  3. Click OK
