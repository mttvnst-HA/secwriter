The SI Editor's Right-click menus provide shortcuts to many commonly used commands.

The context-sensitive Right-click menus adapt to the current SI Editor functions offering actions relevant to your current activity.

Main Right-Click Menus

Click the commands on the image below to learn about the functions available on the Right-click menu.

Standard

  

Selected Text

 

The Standard right-click menu provides additional relevant actions like Check Reference, Check Submittal, Browse to Hyperlink, and Open Referenced Section when you hover and right-click on a Reference (RID), Submittal (SUB), hyperlink (URL), or a Section Reference (SRF).
     

Formatted Table Right-click Menus

Hover Menu

The Hover right-click menu provides additional relevant actions like Check Reference, Check Submittal, Browse to Hyperlink, and Open Referenced Section when you hover and right-click on a Reference (RID), Submittal (SUB), hyperlink (URL), or a Section Reference (SRF).
 

Edit Mode

The Edit right-click menu is available when the Edit Mode is active. To activate this menu, click in the cell, then right-click. This menu offers a variety of helpful tools and for added convenience, includes a full pop-up Table right-click menu.
