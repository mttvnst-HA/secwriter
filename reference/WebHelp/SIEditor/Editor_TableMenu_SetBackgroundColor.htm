This command can also be executed from the SI Editor's Table's Right-click menu.

The Set Background Color for command provides the capability to change the background color in a given column, row, cell, or table.

To learn more, see the Table Tips and Tricks topic.

How To Use This Feature

To Change The Background Color For Selected Cells:

  1. In a Formatted Table, highlight a range of cells and perform one of the following:
    1. Hover over the highlighted cells, right-click and select Set Background Color for, then choose Selected Cells
    2. Select the Table menu and select Set Background Color for, then choose Selected Cells

  1. When the Color window opens, select a Basic color or create a Custom color
  2. Click OK
  3. To save the changes, click outside the table and perform one of the following:
    1. Click the Save button on the Toolbar
    2. Select the File menu and select Save
    3. Use the keyboard shortcut Ctrl+S

To Change The Background Color For A Cell:

  1. In a Formatted Table, perform one of the following:
    1. Hover over a cell, right-click and select Set Background Color for, then select Cell
    2. Click in a cell, press the ESC key to cancel Edit Mode, select the Table menu and select Set Background Color for, then select Cell

  1. When the Color window opens, select a Basic color or create a Custom color
  2. Click OK
  3. To save the changes, click outside the table and perform one of the following:
    1. Click the Save button on the Toolbar
    2. Select the File menu and select Save
    3. Use the keyboard shortcut Ctrl+S

To Create A Custom Color:

  1. When the Color window opens, select one of the blank squares under Custom colors
  2. On the Custom Color Selector, perform one of the following:
    1. Click the desired Color
    2. Use the triangle on the Slider Bar to adjust the color by sliding it up or down
  3. Click the Add to Custom Colors button
  4. Click OK
  5. To save the changes, click outside the table and perform one of the following:
    1. Click the Save button on the Toolbar
    2. Select the File menu and select Save
    3. Use the keyboard shortcut Ctrl+S
