The Toolbar in the SI Editor displays a list of available commands. To customize it, click the Toolbar Options button at the end of the Toolbar.

 

 

Toolbar Buttons & Keyboard Shortcuts Command Description

New

 Creates a new, unnamed file (This command is only available if the SI Editor has been opened from a Master or opened independently from the SpecsIntact Explorer's Tools menu)

Open

 Opens all SpecsIntact file types within the SpecsIntact application, including Section (.sec, .prn), Document (.rpt, .toc, .doc, .ref), and Other (.oth) files.

Save

 Saves the active file.

Print Draft

 Prints a draft copy of the active Section to the default printer (draft printing includes what is visible on-screen, with no headers and footers).

Undo

Reverses the last action, and can be repeated for multiple past actions.

Redo

 Reverses the last undo, and can be repeated for multiple past actions.

Cut

Removes selected text and copies to the systems ClipboardThe Windows Clipboard is a temporary storage location for transferring information. Information is placed in the Clipboard through the cut or copy function and will remain there until you clear the Clipboard, cut or copy another piece of information onto it, or exit Windows (which can be inserted with the Paste command).

Copy

Copies selected text (which can be inserted with the Paste command).

Paste

Pastes the copied or cut text at the cursor location 

Delete

 Removes the selected text without copying it to the Clipboard.

Find

 Searches for specified text.

Find Tags

 Searches for specified tags.

Replace

 Searches for specified text and replaces it with new text.

Replace Brackets

 Launches the Bracket Replacement Tool to find brackets and identify text options.

Next

Continues the Search and Replace functions for other occurrences of specified text.

Revisions

 Enables or disables Revisions. When enabled, it automatically highlights deletions with red  strike-through text surrounded by DEL tags for deleted text and additions with green underscores  surrounded by ADD tags.

Tags

 Turns the on-screen display of Tags on or off.

Notes

 Turns the on-screen display of Notes on or off.

Revisions

 Turns the on-screen display of Revisions on or off.

Marks

 Turns the on-screen display of non-printing characters (e.g., spaces and hard returns) on or off.

Zoom In

 Increases the size of the on-screen display.

Zoom Out

 Decreases the size of the on-screen display.

Change Case

 Provides five distinct options for changing the case of selected text.

Toggle Indentation

 Toggles the Indent for ITM and LST tags back and forth to a default setting of -0.33.

Spell Check

 Launches the spell checker.

Validate

 Verifies that the Section meets all the required tagging and formatting standards before saving. Creates a log that lists any errors found during the check.

Promote Subpart

 Elevates paragraphs or subparagraphs to a higher level in the Section hierarchy.

Help

 Opens the SI Editor's Help.

Toolbar Options

Provides the option to customize the Toolbar by adding or removing buttons.

To learn about a button's function in the SI Editor, hover your mouse cursor over it. A tooltip will appear with a short explanation. This is especially helpful for understanding the tags.
