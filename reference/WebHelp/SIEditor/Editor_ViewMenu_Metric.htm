This command can also be executed from the SI Editor's Right-click menu or by using the keyboard shortcut Alt+M.

The Metric view option enables the display of Metric (MET) measurements within the SI Editor, while the English (ENG) measurements are hidden from view. This setting is optimized for users who primarily work with Metric measurements to improve workflow efficiency. It is important to note that this is not the standard setting for most government projects. 

The SpecsIntact Explorer governs the SI Editor's on-screen display of the Units of Measure. To change the default Units of Measure for a Job within the SpecsIntact Explorer, refer to the File menu > Properties > Options tab. 

By default, the system is automatically set to display Both Units of Measure in Masters.

How To Use This Feature

To Change The On-Screen Units Of Measure View:

  1. In the SI Editor, select the View menu, then select English, Metric, or Both

To Change The Units Of Measure For A Job:

  1. In the SpecsIntact Explorer, select the File menu, then select Properties
  2. In the Properties window, select the Options tab
  3. Below Units of Measure, select English, Metric, or Both
  4. Click OK
