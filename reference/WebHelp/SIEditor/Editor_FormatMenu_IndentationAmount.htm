This command can also be executed from the SI Editor's Toolbar or the Right-click menu.

The TXT / LST / ITM Indentation Amount command provides the option to change the default indentation of the first line of text primarily used for the LST and ITM tags. 

To create a hanging indentation for the TXT, LST, and ITM, a default indentation value of - 0.33 is applied. This negative indentation pushes the first line of each list item to the left, while subsequent lines maintain a standard indentation, resulting in the characteristic hanging indent.

Once the indentation value changes, the Toggle Indentation button or the keyboard shortcut Ctrl+N will return the indentation to its default value.

To streamline list creation in SpecsIntact v5.4 or newer, use the recommended Ordered List feature, which offers automated formatting rather than manual indentation with LST Indent and ITM Indent. 

How To Use This Feature

To Change The Indentation For A Single Occurrence:

  1. In the SI Editor, place your cursor inside a TXT, LST, or ITM tag
  2. Once your cursor is in the desired location, perform one of the following: 
    1. Right-click and select Attributes, then select Indent
    2. Select the Format menu and select TXT / LST / ITM Indentation Amount
  3. In the Tag window, enter the indentation value
  4. Click OK
