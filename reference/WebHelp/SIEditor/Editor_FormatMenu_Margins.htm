The Margins command allows you to change the Units of Measure, Page Margins, and Tab spaces for a specified tag.

Use this function with caution! Modifying the margins will globally impact all SpecsIntact files for all JobsA collection of projects and MastersA collection of Masters consisting of the Unified Facility Guides Specifications (UFGS), local agency or company Masters. These changes will persist until the margins are reset using the Default All button or until the software is reinstalled. 

Tag Margins

  • Units of Measure: Specify the Margins to be measured in Inches or Millimeters.
  • Page Margins: Controls the numerical value for the Top and Bottom Margins.
  • Name: Select the name of the desired tagged element from the drop-down list.
  • Tag: The tag that corresponds to the selected element name.
  • Left: Enter the numeric value for the left margin of the text within the specified tag.
  • Right: Enter the numeric value for the right margin of the text within the specified tag.
  • Center Text: Check the box to center the text between the left and right margins.
  • Tabs: Specify the number of spaces for the cursor to move when you press the Tab key. The default tab value is three.

Button Functionality

  • Default: Reverts the margin settings to the default values specified for the selected tag and restores the inherited font relationships.
  • Default All: Returns all tags to the SpecsIntact default margin settings.

Standard Windows Commands

The OK button will execute and save the selections made.

The Cancel button will close the window without recording any selections or changes entered.

The Help button will open the Help Topic for this window.

How To Use This Feature

To Change Margins:

  1. In the SI Editor, perform one of the following:
    1. Select the Format menu and select Margins
    2. Use the keyboard shortcut Alt+D
  2. In the Margins window, below Units of Measure select the Inches or Millimeters
  3. Below Page Margins, enter the desired number for the Top and Bottom Margins
  4. Click OK

To Reset Margins:

  1. In the SI Editor, perform one of the following:
    1. Select Format menu and select Margins
    2. Use the keyboard shortcut Alt+D
  2. In the Margins window, click Default All
  3. Click OK
