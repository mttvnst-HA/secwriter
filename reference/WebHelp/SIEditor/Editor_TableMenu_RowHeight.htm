This command can also be executed from the SI Editor's Table's Right-click menu.

The Row Height command provides the ability to specify the height of rows within Formatted Tables.

In the event of an error, click outside the table and use the Undo (Ctrl+Z) command.  To learn more, see the Table Tips and Tricks topic.

Standard Windows Commands

The OK button will execute and save the selections made.

The Cancel button will close the window without recording any selections or changes entered.

How To Use This Feature

To Adjust Individual or Multiple Rows To A Specific Height:

  1. In a Formatted Table, select the table or row(s)
  2. Once the table or row(s) are highlighted, perform one of the following:
    1. Right-click and select Row Height
    2. Select the Table menu and select Row Height
  3. When the Row Height window opens, perform one of the following:
    1. Type the value in the field
    2. Use the arrows to increase or decrease the value
  4. Click OK
  5. To save the changes, click outside the table and perform one of the following:
    1. Click the Save button on the Toolbar
    2. Select the File menu and select Save
    3. Use the keyboard shortcut Ctrl+S

To Adjust a Row Height with the Cursor:

When adjusting rows using the mouse, it is recommended that you start adjusting the rows from the bottom of the Formatted Table to the top.

  1. In a Formatted Table, hover over the row border until the cursor changes to a double-headed arrow
  2. Click-and-drag the border until the row is the desired height

  1. To save the changes, click outside the table and perform one of the following:
    1. Click the Save button on the Toolbar
    2. Select the File menu and select Save
    3. Use the keyboard shortcut Ctrl+S
