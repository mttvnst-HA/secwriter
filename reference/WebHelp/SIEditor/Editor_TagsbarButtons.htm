SI Editor Tagsbar Buttons 

In this Topic HideIn this Topic Show
  1. Additional Learning Tools
  2. Technical Support Information

The Tagsbar in the SI Editor displays a list of available commands. To customize it, click the Toolbar Options button at the end of the Tagsbar.

 

 

Tagsbar Buttons and Keyboard Shortcuts Command Description
Part

Specifies a hierarchical structure with a parent Part, child Subpart, and associated text.
Subpart

Specifies a Subpart with a title and associated text.
Title

Specifies the Title for a PART, ARTICLE, Paragraph, and Subparagraph.
Text Specifies textual content.
List

Specifies a List with .50 margin.
Item

Specifies an Item with .85 margin.
Indented List 

Specifies an Indented List with a  -0.33 indentation set.
Indented Item

Specifies an Indented Item with a  -0.33 indentation set.
Metric

Specifies Metric measurements.
  English

Specifies English measurements.
Reference

Specifies a Reference in the Reference Article encompassing attributes such as the referencing organization, a unique identifier, and a title.
Reference Identifier

Specifies the Reference Identifier with its acronym and number.
Reference Title

Specifies the Reference Title with its publication date and title.
Reference Organization

Specifies the Reference Organization name and its acronym.
Reference Organization Address

Specifies the Reference Organization Address exclusively used in the 01 42 00 Sources for Reference Publications Section.
Submittal Key

Specifies the Submittal Key to identify each Submittal within the Submittals Article and text.
Section Reference

Specifies a Section Reference number to identify cross-references to other Sections followed by the Section Title.
URL Hyperlink

Specifies hyperlinks to relevant websites and other online resources.
Note

Specifies the technical notes relevant to the specifier.
Note Paragraph

Specifies paragraphs within a technical note.
Unformatted Table

Specifies an Unformatted Table, including the table header, using spaces to separate columns and rows. Formatted Tables have superseded this table format.
Test Requirements

Specifies the required Test Requirements.
Change

Specifies changes to a Section -- No longer in use and hidden by default.
Section Attachment

Specifies the documents to be included in the Section Table of Contents and manually inserted into the bid package.
Date

Specifies the date the Section was initially established or the date of its most recent major maintenance activity.
Scope

Specifies the purpose and objective of a Section.
Section Title

Specifies the Title of a Section.
Ordered List Group Specifies the group tag used to surround the listed items.
Ordered List Specifies a multi-level Ordered List that is automatically numbered.
Highlight

Specifies certain highlighted text to draw attention to it for review.
Bold

Specifies Bold formatting for stronger emphasis.
Italic

Specifies Italicized formatting for emphasis.
Underline

Specifies Underlined formatting to text.
Center

Specifies center text alignment.
Formatted Table 

Specifies a Formatted Table with options for rows, columns, and cell styles.

Toolbar Options Provides the option to customize the Tagsbar by adding or removing buttons.

To learn about a button's function in the SI Editor, hover your mouse cursor over it. A tooltip will appear with a short explanation. This is especially helpful for understanding the tags.
