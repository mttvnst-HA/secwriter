This command can also be executed from the SI Editor's Toolbar, Right-click menu, or by using the keyboard shortcut Ctrl+B.

The Bracket Replacement tool provides an automated process for identifying Bracketed OptionsText presented with bracketed choices, allowing users to select the desired option to select or fill in the option to be included in the specification. Unselected options and their corresponding brackets are removed.

Replace Bracketed Text

Button Functionality

  • Select Item(s) to Replace Bracketed Text: Lists the options enclosed in brackets for selection.
  • Replace: Inserts the chosen option(s) while removing both the brackets and unselected options.
  • Ignore: Retains the current options and brackets then proceeds to the next set of brackets within the SectionA set of files within the Division of a Master or Job that covers specific aspects of construction.
  • Cancel: Closes the Replace Bracketed Text window and returns to the SI Editor.
  • Help: Opens the Help file for the active window.
  • Undo Last: Reverses the Bracket Replacement actions individually, starting with the last change made. The Undo Last button is disabled when using Pause After Each Change.
  • Show or Hide Details: Controls which features appear below.

Replace Bracketed Text With:

  • Selected item(s), above: Inserts chosen options while removing both unselected options and brackets.
  • Existing text (remove brackets): Inserts all options and removes the brackets.
  • No text: Removes all options and brackets.
  • New Text, below: Removes all options and brackets, then inserts the text entered in the text box.

 For inserting smaller amounts of text, the New Text, below option is preferable. However, when inserting a larger amount of text it is recommended to enter the text directly when editing the Section. 

Don't Move This Dialog box

When checked, the screen position remains fixed, even if the window covers the selected bracketed options within the Section.  When unchecked, the window will automatically adjust its position to display the location of the bracketed options within the Section text.

Replace deletions with spaces in old, unformatted tables

This applies to the Unformatted Tables and will not change the way Formatted Tables are handled.  Within an Unformatted Table, this option will replace any character deleted from a table during bracket replacement with a space to preserve the table layout.

Using Bracket Replacement within Formatted Tables will not delete empty rows or columns when all the bracketed options are removed.  Use the Table menu to Delete empty rows or columns.

Occurrences Found / Edited

A counter that tracks how many bracketed options have been found and edited since the function was activated. The counter resets when the window is closed (including when the Pause After Each Change check box is used).

Pause After Each Change

When you replace the bracketed text, your cursor will remain in place, and the window will close without moving to the next occurrence. This allows you to remain in the same location to continue editing. When this option is turned off, it will continue to process all the bracketed options in the Section, stopping when it reaches the end of the Section.

The counter is not available when using this option.

To continue to find subsequent occurrences, use the F3 key or the Find Next button on the SI Editor's Toolbar.

How To Use This Feature

To Use the Bracket Replacement by selecting options:

  1. In the SI Editor, perform one of the following:
    1. Right-click and select Bracket Replacement
    2. Click the Replace Brackets button located on the Toolbar
    3. Select the Edit menu and select Bracket Replacement
    4. Use the keyboard shortcut Ctrl+B
  2. In the Replace Bracketed Text window, begin by selecting the Show Details button (Only done once)
  3. Under Occurrences, select Pause After Each Change
  4. Under Select Item(s) to Replace Bracketed Text, select one or more of the listed options
  5. Click the Replace button

If you do not want to keep any of the listed bracketed options, do not select any of the options under the Select Items(s) to Replace Bracketed Text window, then click the Replace button.  This will remove all the text and brackets.

To choose multiple selections, click the first option, hold the Shift Key, then click the last option. All highlighted items will be inserted, while brackets and unselected options will be removed. To select non-sequential options while removing brackets and unselected options, hold the Ctrl Key and click on the desired choices.

To Use the Bracket Replacement to enter new text:

  1. In the SI Editor, perform one of the following:
    1. Right-click and select Bracket Replacement
    2. Click the Replace Bracket button on the Toolbar
    3. Select the Edit menu and select Bracket Replacement
    4. Use the keyboard shortcut Ctrl+B
  2. Under Select Item(s) to Replace Bracketed Text, select the underscore option so it is highlighted
  3. Under Replace Bracketed Text With, select New Text, below
  4. Enter the text to replace, then click the Replace button
