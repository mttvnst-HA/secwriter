This command can only be executed from the SI Editor's File menu.

The Save As command will save the active file with a new name or to a different location on your system. This command is only available when working with a Master specification or when a Section is opened directly from the SI Editor, rather than from within SpecsIntact.

How To Use This Feature

To Save A File With a Different Name or Location:

  1. In the SI Editor, select the File menu and select Save As
  2. In the Save As window, enter a new File name or navigate to the desired location
  3. Click Save
