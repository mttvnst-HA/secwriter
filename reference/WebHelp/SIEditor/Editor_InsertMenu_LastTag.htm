SI Editor Insert Menu - Last Tag

This command can also be executed from the Editor's Insert menu or by using the keyboard shortcut F2.

The Insert Last Tag command will repeat the previous or last tag selected from the SI Editor's Tagsbar or Insert > Tags. This function is also beneficial when entering text or inserting other tagged elements such as the ITM, Indented ITM, LST, or Indented LST tags.

Before using the Insert > Tags function, as well as any other editing function, it is recommended that the tags are visible (View > Tags or by clicking the Toolbar Show Tags   button).

Tailoring tags are distinctive and have unique attributes that prevent duplication, so this command will not reinsert them.

The most commonly used tags may be inserted using the Tagsbar buttons. The Tagsbar provides an easy method for tagging frequently used elements within the specification.

Discover how to create, modify, and utilize the Last Tag feature in Ordered Lists.

How To Use This Feature

To Insert the Last Used Tag

  1. On the Tagsbar, click one of the buttons (e.g., TXT, ITM, ITM Indent, LST, or LST Indent)
  2. Enter the Text then move the cursor outside of the tags (e.g., left of the ending tag </TXT> </ITM>)
  3. Press the Enter key twice to double-space the text
  4. Press the F2 key to insert the last used tag
  5. Continue pressing the F2 key until finished
