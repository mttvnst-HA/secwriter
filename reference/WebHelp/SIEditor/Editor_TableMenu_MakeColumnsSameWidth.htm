This command can also be executed from the SI Editor's Table's Right-click menu.

The Make Columns Same Width command evenly distributes the width of all columns within the table to ensure all columns have equal width. The total width of the table remains the same, and the available space is evenly divided based on the overall table width. The table width cannot exceed 100 within the margin settings.  To create equal column widths, use the mouse to adjust any one column, then right-click and select Make All Columns Same Width. This works for both increasing and decreasing column sizes.

In the event of an error, click outside the table and use the Undo (Ctrl+Z) command.  To learn more, see the Table Tips and Tricks topic.

How To Use This Feature

To Make All Columns The Same Width:

  1. In a Formatted Table, perform one of the following:
    1. Hover over the table, right-click and select Make All Columns Same Width
    2. Click in a cell, select the Table menu and select Make Columns Same Width
  2. To save the changes, click outside the table and perform one of the following:
    1. Click the Save button on the Toolbar
    2. Select the File menu and select Save
    3. Use the keyboard shortcut Ctrl+S
