This command can also be executed by using the keyboard shortcut Ctrl+G.

The Go To Page command will move the cursor from the current location to the top of the page you specify in the Page Number field.

How To Use This Feature

To Navigate To A Specific Page:

  1. In the SI Editor, perform one of the following:
    1. Select the Edit menu and select Go To Page
    2. Use the keyboard shortcut Ctrl+G
  2. In the Go To Page window, enter the page number in the field or use the arrows to move the number up or down
  3. Click OK
