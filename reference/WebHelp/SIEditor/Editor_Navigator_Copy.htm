This command can be executed from the SI Editor's Navigator's Right-click menu or by using the keyboard shortcut Ctrl+C.

The Copy command copies the selected Subpart and places it in the Windows ClipboardThe Windows Clipboard is a temporary storage location for transferring information. Information is placed in the Clipboard through the cut or copy function and will remain there until you clear the Clipboard, cut or copy another piece of information onto it, or exit Windows.  To paste the SubpartThe levels below a Part are referred to as Subparts. These Subpart levels are then broken down into and referenced as Articles, Paragraphs and Subparagraphs, although the share the same Subpart <SPT> Tag and its text, you must do so from the Editing window.

When copied text is pasted, it will be tracked with RevisionsThe Revisions command reveals or conceals Revisions that are tagged in the text. Text to be added is identified with underscoring and the addition tags, <ADD> and </ADD>. Whereas text to be deleted, or Redlined, is identified with overstriking and the delete tags, <DEL> and </DEL>, if the project is configured to use them. When using Revisions and the text is pasted to another location, the Navigator's icon transforms to green. While editing within the Navigator, the SI Editor's Undo and Redo commands can be used.

To learn more about the Navigator, refer to the Navigator Overview topic.

the Navigator's Drag-and-Drop:

The Drag-And-Drop method to copy a Subpart provides greater flexibility and precise control over the placement of Subparts, streamlining the copying process by eliminating separate Copy and Paste commands. When you right-click and drag a Subpart, a pop-up menu appears, allowing you to copy the selected Subpart before, into, or after another Subpart.

To learn more about using the Drag-and-Drop method to move Subparts, refer to the SI Editor's Navigator Move topic.

How To Use This Feature

To Copy a Subpart using the Navigator:

The Navigator's right-click Copy command is more efficient for pasting Subparts within the Editing window.

  1. In the Navigator, select the Subpart you wish to copy
  2. Once the Subpart is highlighted, perform one of the following:
    1. Right-click and select Copy 
    2. Use the keyboard shortcut Ctrl+C

To copy a Subpart using the Navigator's Drag-and-Drop:

  1. In the Navigator, select the Subpart you wish to copy
  2. Right-click and drag to the desired location, then release
  3. When the Move and Copy pop-up menu appears, select one of the following:
    1. Copy Before
    2. Copy Into
    3. Copy After
