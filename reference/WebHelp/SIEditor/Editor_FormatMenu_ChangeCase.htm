This command can also be executed from the SI Editor's Toolbar, Right-click menu, or by using the keyboard shortcut Alt+K.

The Change Case command provides a range of case-conversion options to modify the capitalization of selected text.

Change Case

  • lower case: The selected text will appear in lowercase.
  • UPPER CASE: The selected text will appear in UPPERCASE.
  • oPPOSITE cASE: The selected text will be transformed from the current case to the opposite case. For instance, all lower will become UPPER, likewise, all UPPER will become lower.
  • Title Case: The first letter of each word is capitalized.
  • Sentence case: The first letter of a sentence is capitalized and all other words are lowercase.

The last selected setting becomes the new default to enable repetitive changes.

Standard Windows Commands

The OK button will execute and save the selections made.

The Cancel button will close the window without recording any selections or changes entered.

How To Use This Feature

To Change The Case For Selected Word:

  1. In the SI Editor, select the text
  2. Once the text is selected, perform one of the following:
    1. Right-click and select Change Case
    2. Click the Change Case button on the Toolbar
    3. Select the Format menu and select Change Case
    4. Use the keyboard shortcut Alt+K
  3. In the Change Case window below Change to, select one of the following:
    1. lower case
    2. UPPER CASE
    3. oPPOSITE cASE
    4. Title Case
    5. Sentence case
  4. Click OK
