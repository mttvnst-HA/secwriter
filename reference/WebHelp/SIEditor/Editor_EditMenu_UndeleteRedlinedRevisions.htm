This command can also be executed from the SI Editor's Right-click menu or by using the keyboard shortcut Ctrl+U.

The Undelete Redlined Revisions command restores previously deleted text by removing the DEL tagsSpecsIntact relies on tags to control content, and formatting, automate processes, and generate reports. These special markers, like <SEC> and </SEC>, define elements and attributes within the specifications. Some tags, like <Page />, function independently. In essence, tags are the building blocks of SpecsIntact documents and redlining.

If no text is selected, all redlined text within the SectionA set of files within the Division of a Master or Job that covers specific aspects of construction is restored. If specific redlined text is selected, only the selected text is restored. In either case, the corresponding DEL tags are removed.

The Undo command provides the capability to reverse the results of this function prior to saving changes. Once the changes are saved, they become irreversible.

Examples

You have used the Revisions function to mark the following text for deletion:

<DEL>SpecsIntact will not unmark the selected text</DEL>

If you select the word "not" and select Edit > Undelete Redlined Revisions, or right-click and select the same option, the result would be:

<DEL>SpecsIntact will not unmark the selected text</DEL>

The Undelete Redlined Revisions command is specifically designed to restore deleted text. It does not affect text that has been marked for addition and is enclosed within ADD tags. To remove added text, use the Delete Added Revisions command, and to reverse both added and deleted text simultaneously, use Remove All Revisions.

How To Use This Feature

To Undelete Specific Redlined Text:

  1. In the SI Editor, select the desired Redlined (deleted) text
  2. Once the text is highlighted, perform one of the following:
    1. Right-click and select Undelete Redlined Revisions
    2. Select the Edit menu and select Undelete Redlined Revisions 
    3. Use the keyboard shortcut Ctrl+U

To Undelete All Redlined Revisions:

  1. In the SI Editor, perform one of the following:
    1. Select the Edit menu and select Undelete Redlined Revisions 
    2. Use the keyboard shortcut Ctrl+U
  2. When the confirmation window opens, click Yes
