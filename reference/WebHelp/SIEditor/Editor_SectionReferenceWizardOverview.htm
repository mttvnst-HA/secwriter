The Section Reference Wizard streamlines the process of Section management by enabling cross-referencing between Sections, aiding in quality assuranceA systematic process insuring the specification meets the specified requirements set by the UFGS Discipline Working Group as documented within the Unified Facilities Guide Specifications (UFGS) Format Standard (UFS 1-300-02) and quality control of critical project elements by automating the Section and Section References insertion, using the SRF tags to identify and standardize Section Numbers and Titles. This automated tool eliminates manual entry to improve the accuracy of the Section Verification Report.

The Section Reference Wizard is activated by positioning the cursor within the Section text and clicking the SRF button on the Tagsbar.

While not recommended, you can disable the Section Reference Wizard by navigating to the Tools menu > Options > Edit and unchecking Use Submittal and Section Reference Wizards.

When the Section Reference Wizard opens, it will initially display Sections within the selected Job. If the required Section is located in a connected Master, the software will provide an option to incorporate the Section into the selected Job.

Features

  1. Select a Section from this list, or choose another list below to select Sections from it: Provides the flexibility to select a Section from the current list or select from a different list using the Show Sections from option.
  2. Show Sections from: Provides the option to add a Section from the current Job or a connected Master.
  3. Use Empty Tags: Permits the insertion of blank tags instead of a selection from the window for manually inserting Section References.

How To Use This Feature

To automatically add a Section Reference:

  1. In the Editing window, place your cursor where you want to insert a Section Reference (SRF)
  2. To activate the Section Reference Wizard, click the SRF button on the Tagsbar 
  3. When the Section Reference Wizard opens, perform any of the following:
    1. Select the Section from the list 
    2. Click the drop-down arrow to select a list from the available Masters
  4. Click OK

To Manually add a Section Reference:

  1. In the Editing window, place your cursor where you want to insert a Section Reference (SRF)
  2. To activate the Section Reference Wizard, click the SRF button on the Tagsbar 
  3. When the Section Reference Wizard opens, check Use empty tags
  4. Click OK
  5. Enter the Section Number within the inserted SRF tags,
  6. Enter the corresponding Section Title outside and to the right of the ending SRF tag
