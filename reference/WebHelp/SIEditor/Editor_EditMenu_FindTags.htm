This command can also be executed from the SI Editor's Toolbar, Right-click menu, or by using the keyboard shortcut Ctrl+I.

The Find Tags command allows you to search for specific tagsSpecsIntact relies on tags to control content, and formatting, automate processes, and generate reports. These special markers, like <SEC> and </SEC>, define elements and attributes within the specifications. Some tags, like <Page />, function independently. In essence, tags are the building blocks of SpecsIntact documents using the Find Tags window as illustrated below:

Select Tag to Find 

Use the Name drop-down list to select the name of the tag you wish to find, the tag will be displayed to the right of the field.

Find

Select whether to search on Begin Tags, End Tags, or Both.

Attribute

To find a tag with a specific attribute, check the Find tags only with the following attribute value option and enter the user-specific attribute in the text field. There are a limited number of tags that are designed to include user-specific attributes, such as Tailoring (TAI), Submittals (SBM), Ordered List (OLI), Text (TXT), List (LST), or Item (ITM) tags.

For example, the Tailoring (TAI) tags contain attributes such as ARMY, NAVY, or AIR FORCE, etc., and the Submittal (SBM) tags -- in the 01 33 00 Submittal Procedures Section -- contain the Submittal Description Numbers (01 - 11). Text, List, and Item tags may include attributes such as Indentation (-0.33, etc.), Justification (Left, Right, or Center), or Style (Bold, Italic, or Underline) attributes.

Search

From Cursor

The option to search From Cursor will search from the cursor location to the end of the file.

Entire File

The option to search the Entire File will search the file from the beginning to the end.

Standard Windows Commands

The OK button will execute and save the selections made.

The Cancel button will close the window without recording any selections or changes entered.

The Help button will open the Help Topic for this window.

How To Use This Feature

To search for a specific tag:

  1. In the SI Editor, perform one of the following:
    1. Right-click and select Find Tags
    2. Click the Find Tags button on the Toolbar
    3. Select the Edit menu and select Find Tags
    4. Use the keyboard shortcut Ctrl+I
  2. Below Select Tag to Find, click the drop-down arrow, then scroll down the list, or type the first letter of the tag until the tag you want is highlighted
  3. Below Find, select whether to find Beginning Tags, Ending Tags, or Both
  4. Below Search, select whether to search the Entire File or From Cursor
  5. Click OK

To find the next instance of the same tag, press the F3 key.

To search for a specific tag Attribute:

  1. In the SI Editor, perform one of the following:
    1. Right-click and select Find Tags
    2. Click the Find Tags button on the Toolbar
    3. Select the Edit menu and select Find Tags
    4. Use the keyboard shortcut Ctrl+I
  2. Below Select Tag to Find, click the drop-down arrow, then scroll down the list, or type the first letter of the tag until the desired tag is highlighted
  3. Below Find, select whether to find Beginning Tags, Ending Tags, or Both
  4. Below Attributes, check Find tags only with the following attribute value, and type the attribute in the text field
  5. Below Search, select whether to search the Entire File or From Cursor
  6. Click OK

To find the next instance of the same tag, press the F3 key.
