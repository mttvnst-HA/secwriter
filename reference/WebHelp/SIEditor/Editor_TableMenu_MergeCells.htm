This command can also be executed from the SI Editor's Table's Right-click menu.

The Merge Cells command combines selected cells within a row or column into a single cell.

Merging cells that exceed page boundaries can lead to data truncation. To ensure proper data display and optimal PDF formatting, utilizing multiple smaller tables is generally recommended.

In the event of an error, click outside the table and use the Undo (Ctrl+Z) command. To learn more, see the Table Tips and Tricks topic.

How To Use This Feature

To Merge Cells:

  1. In a Formatted Table, perform one of the following:
    1. Click-and-drag to highlight the range of cells
    2. Click the first cell, press-and-hold the Shift key, then click the last cell in the range
    3. Click the first cell, press-and-hold the Shift key, then press the right arrow to select the range of cells
  2. Once the cells are highlighted, perform one of the following:
    1. Hover over the selected cells, right-click and select Merge Cells
    2. Select the Table menu and select Merge Cells
  3. To save the changes, click outside the table and perform one of the following:
    1. Click the Save button on the Toolbar
    2. Select the File menu and select Save
    3. Use the keyboard shortcut Ctrl+S
