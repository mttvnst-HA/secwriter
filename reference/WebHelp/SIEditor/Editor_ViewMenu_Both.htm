This command can also be executed from the SI Editor's Right-click menu or by using the keyboard shortcut Alt+B.

The Both view option is primarily used to enable the simultaneous display of Metric Measurements and English Measurements within the SI Editor. This simplifies the comparison and manipulation of measurements in either system, enhancing flexibility and convenience for projects.  This is the default view setting for Masters.

How To Use This Feature

To Change The On-Screen Units Of Measure View:

  1. In the SI Editor, select the View menu, then select English, Metric, or Both

To Change The Units Of Measure For A Job:

  1. In the SpecsIntact Explorer, select the File menu, then select Properties
  2. In the Properties window, select the Options tab
  3. Below Units of Measure, select English, Metric, or Both
  4. Click OK
