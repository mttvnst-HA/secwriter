This command can also be executed from the SI Editor's Right-click menu.

The Tailoring command serves as a management tool for TailoringTagged elements <TAI> </TAI> inserted by the Master Specification writer to indicate specific elements within a specification. These tags allow them to include or exclude requirements based on factors like agency or product. This pre-editing removes irrelevant requirements, simplifying customization for each project Options, offering the functionality to establish new options or eliminate existing ones.

Tailoring

The Tailoring feature facilitates specification editing by providing a mechanism for pre-editing text segments designated with TAI tags by the UFGS Technical Proponent. This empowers specification editors to selectively include or exclude entire portions of text, thereby eliminating the need for manual editing of individual occurrences of irrelevant requirements.

To learn more about using Tailoring in the UFGS Master specifications, refer to the Unified Facilities Guide Specifications (UFGS) Format Standard (UFS 1-300-02).

Add Tailoring Options

Tailoring Options are integrated into the specification by the UFGS Technical Proponents during the creation of Master specifications. This allows for customization by enabling the exclusion of irrelevant project requirements, thereby ensuring a tailored and efficient specification.

To streamline the insertion of Tailoring Options and eliminate redundancy, the Add Tailoring Options window provides a convenient interface to select existing options from the active Section or UFGS Master. 

Adding Multiple Tailoring Options

SpecsIntact allows for multiple options within a single Tailoring Option when the tailored content applies to more than one category (e.g., Agency, project methods, locations, or products). Use commas without spaces to separate options (e.g., Army,Navy,Air Force).

There is a sixty (60) character limit per option within the Tailoring tag.

Remove Tailoring Options

This function removes individual instances of Tailoring Options from the TAI tag.  For example, if the TAI tag is <TAI OPT=ARMY,NAVY,DESIGN-BID-BUILD>, you can remove 'DESIGN-BID-BUILD' resulting in <TAI OPT=ARMY,NAVY>.  In the case of a single option, the option and accompanying TAI tag will be deleted.  This action only affects the specific occurrence, leaving other instances within the Section unaffected.

How to Use This Feature

To Add A Tailoring Option:

  1. In the SI Editor, select the tagged element or desired text to apply Tailoring to
  2. Once the tagged element or text is highlighted, perform one of the following:
    1. Right-click and select Insert Tailoring
    2. Select the Insert menu, select Tailoring, then select Add Tailoring Options
  3. In the Add Tailoring Options window, perform one of the following:
    1. In the Options in Section, select an option from the available list to maintain consistency
    2. Click the Options in Master UFGS and select an option from the available list to maintain consistency
  4. Place your cursor in the empty field below Tailoring Option and type a new option 
  5. Click OK

To Add Multiple Tailoring Options:

  1. In the SI Editor, select the tagged element or desired text to apply Tailoring to
  2. Once the tagged element or text is highlighted, perform one of the following:
    1. Right-click and select Insert Tailoring
    2. Select the Insert menu, select Tailoring, then select Add Tailoring Options
  3. To add multiple options in the Add Tailoring Options window, perform one of the following:
    1. Press-and-hold the Ctrl key or Shift key, then select additional options from one or both of the available lists to maintain consistency
    2. Place your cursor in the empty field below Tailoring Option and type a new option, then press-and-hold the Shift key or Ctrl key to select additional options from the available lists to maintain consistency
    3. Place your cursor in the empty field below Tailoring Option and type each new option followed by a comma with no spaces (e.g., PIPES,COPPER)
  4. Click OK

 Use the Ctrl key for individual non-consecutive selections and the Shift key for grouped consecutive options.

To Modify Existing Tailoring Options:

The software allows you to modify Tailoring (TAI) tags by adding or removing options as needed. This flexibility is helpful for situations where a change is required, such as replacing 'USACE' with 'Army'. To make this change, you would add 'Army' as a new Tailoring Option, then remove the outdated 'USACE' option. To do this, perform the following steps:

  1. In the SI Editor, place your cursor inside the TAI tag you wish to modify (e.g., <TAI OPT=USACE>)
  2. Right-click and select Attributes > Tailoring > Add Option
  3. In the Tailoring Options window, place your cursor in the field below Tailoring Option and type the new option (e.g., 'ARMY')
  4. Click OK
  5. With your cursor still positioned inside the same Tailoring tag (e.g., <TAI OPT=USACE,ARMY>), right-click and select Attributes > Tailoring > Delete Option
  6. In the Tailoring Options window, select the incorrect Tailoring Option from the list (e.g., 'USACE')
  7. Click OK
