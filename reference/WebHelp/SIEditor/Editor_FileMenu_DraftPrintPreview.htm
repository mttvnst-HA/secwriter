This command can only be executed from the SI Editor's File menu.

The Draft Print Preview command allows you to preview the SectionA set of files within the Division of a Master or Job that covers specific aspects of construction, navigate between pages, change the display, zoom in or out, print, or close the preview. The printed output of a draft section will match the content shown in the SI Editor, including RevisionsThe Revisions command reveals or conceals Revisions that are tagged in the text. Text to be added is identified with underscoring and the addition tags, <ADD> and </ADD>. Whereas text to be deleted, or Redlined, is identified with overstriking and the delete tags, <DEL> and </DEL>, TagsSpecsIntact relies on tags to control content, and formatting, automate processes, and generate reports. These special markers, like <SEC> and </SEC>, define elements and attributes within the specifications. Some tags, like <Page />, function independently. In essence, tags are the building blocks of SpecsIntact documents, and the Specifier NotesSpecifier Notes <NTE> are paragraphs of information included in the Section written to aid the Engineer, Architect, or Specifier in editing the specification.

The printed draft output of a section will accurately reflect its on-screen view in the SI Editor. This includes any visible Revisions, Tags, and the Specifier Notes.

How To Use This Feature

To Use Draft Print Preview:

  1. In the SI Editor, select the File menu, then select Draft Print Preview
  2. On the Draft Print Preview window, you can perform one of the following:
    1. Print
    2. Next Page / Previous Page
    3. Toggle One / Two Pages Display
    4. Zoom In / Zoom Out
    5. Close

To generate the final output, use the SpecsIntact Explorer's File > Process and Print/Publish command to process and print the Section(s).
