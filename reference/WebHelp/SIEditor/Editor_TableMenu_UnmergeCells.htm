This command can also be executed from the SI Editor's Table's Right-click menu.

The Unmerge Cells command provides the capability to separate merged cells into the original number of cells used when the formatted table was created.

When unmerging cells, the text will remain in the first cell of the merged area.

In the event of an error, click outside the table and use the Undo (Ctrl+Z) command.  To learn more, see the Table Tips and Tricks topic.

How To Use This Feature

To Unmerge Cells:

  1. In a Formatted Table, perform one of the following:
    1. Hover over a merged cell, right-click and select Unmerge Cells 
    2. Click in a merged cell, select the Table menu and select Unmerge Cells
  2. To save the changes, click outside the table and perform one of the following:
    1. Click the Save button on the Toolbar
    2. Select the File menu and select Save
    3. Use the keyboard shortcut Ctrl+S
