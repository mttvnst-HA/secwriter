This command can also be executed from the SI Editor's Table's Right-click menu.

The Export Excel XML Spreadsheet command will export an existing Formatted Table to an Excel XML Spreadsheet.

The SI Editor allows users to copy multiple formatted table cells and paste them into other SpecsIntact tables or external applications such as Microsoft Excel and Word. This feature particularly benefits government users whose security protocols prevent direct export to third-party applications.

How To Use This Feature

To Export A Formatted Table to An Excel XML Spreadsheet:

  1. In a Formatted Table, perform one of the following:
    1. Hover over the table, then right-click and select Export Excel XML Spreadsheet
    2. Place your cursor in any cell, then select the Table menu and select Export Excel XML Spreadsheet

  1. In the Specify a File Name window, navigate to the desired location
  2. In the File Name field, type the filename
  3. Click Save
  4. When the confirmation window opens, click OK

To Copy and Paste A Formatted Table's Contents To Excel:

  1. In a Formatted Table, perform one of the following:
    1. Hover over the table, then right-click and choose Select Table
    2. Place your cursor in any cell, then select the Table menu and choose Select Table
  2. Once the table is highlighted, hover your cursor over the selected table, then perform one of the following:
    1. Right-click and select Copy Without Tags
    2. Select the Edit menu and select Copy Without Tags
    3. Use the keyboard shortcut Ctrl+E
  3. Open Microsoft Excel and place the cursor in the first cell, then perform one of the following:
    1. Right-click and select Paste
    2. Select the Paste button on the Toolbar
    3. Use the keyboard shortcut Ctrl+V

To Copy and Paste A Formatted Table's Contents To Word:

  1. In a Formatted Table, perform one of the following:
    1. Hover over the table, then right-click and choose Select Table
    2. Place your cursor in any cell, then select the Table menu and choose Select Table
  2. Once the table is highlighted, hover your cursor over the selected table, then perform one of the following:
    1. Right-click and select Copy Without Tags
    2. Select the Edit menu and select Copy Without Tags
    3. Use the keyboard shortcut Ctrl+E
  3. Open Microsoft Word and insert a new table that mirrors the existing SpecsIntact table
  4. Highlight the entire table, then perform one of the following:
    1. Right-click and select Paste
    2. Select the Paste button on the Toolbar
    3. Use the keyboard shortcut Ctrl+V
