This command can also be executed from the SI Editor's Toolbar, Right-click menu, or by using the keyboard shortcut Ctrl+Y.

The Redo command allows you to reverse single or multiple executed Undo actions.  This command is convenient when the Undo command is used too many times.

 To learn more about the Navigator, refer to the Navigator Overview topic.

How To Use This Feature

To Redo edits from the Editing Window:

  1. In the SI Editor, perform one of the following:
    1. Right-click and select Redo
    2. Click the Redo button on the Toolbar
    3. Select the Edit menu and select Redo
    4. Use the keyboard shortcut Ctrl+Y
