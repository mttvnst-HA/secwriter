This command can also be executed by using the keyboard shortcut Alt+L.

The Color view option toggles the tag color-coding on or off.  The color-coding is used within the text to quickly identify some of the tagged elements within a SectionA set of files within the Division of a Master or Job that covers specific aspects of construction, improving visual recognition. The color-coding for each tag corresponds to the color of the associated Toolbar button.

Click the tag option below to display each command.

Tag Description Color-Coding
ADD Addition Green
DEL Deletion Red
ENG English Dark Blue
MET Metric Dark Red
RID Reference Identifier Light Magenta
SRF Section Reference Violet
SUB Submittal Blue
TAI Tailoring Option Teal
URL Hyperlink Dark Yellow
HLS Highlight Orange
