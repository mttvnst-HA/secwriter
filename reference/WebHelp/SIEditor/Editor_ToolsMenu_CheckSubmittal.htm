This command can also be executed from the SI Editor's Right-click menu.

The Check Submittal command is available when the cursor is placed between the Submittal (SUB) tags within the Section's Submittal Article or text. This functionality enables automatic cross-referencing of the Submittal Item with those in the Submittal ArticleAn Article within Part 1 that contains a list of the Submittals Descriptions along with the Submittal Items as used in the section text and those within the body of the Section, outside the Submittal Article.

This feature applies only to Submittal Items, not Submittal Descriptions (SD-01 through SD-11).  Submittal Checking cannot be used within Tables.

Check Submittals In The Submittal Article

Checking Submittals confirms if a Submittal Item from the Submittal Article exists in the Section text (outside the Submittal Article) and identifies differences (e.g., Receipts vs. Receipt). If the Submittal Item is found with differences or is missing, you must either enclose it in SUB tags within the Section text or delete it from the Submittal Article. Ensure the Submittal Item is identical in both locations.

Check Submittals In The Section Text

Checking Submittals within the text, outside the Submittal Article, identifies if a Submittal Item is missing from the Submittal Article and offers to add it. At this point, you would perform one of the following:

  • Selecting Yes opens the Submittal Wizard to guide you through the addition process.  
  • Selecting No indicates the requirement is obsolete, allowing you to remove the SUB tags or delete the Submittal Item and its related text (e.g., Subpart or sentence).

To learn more about removing tags, refer to the Remove Tags topic.

How to Use This Feature

To Check the Submittal Item From Within the Section Text:

  1. In the Section text, locate a Submittal Item and place your cursor between the SUB tags, then perform one of the following:
    1. Right-click and select Check Submittal
    2. Select the Tools menu and select Check Submittal
  2. If the Submittal Item matches the one in the Submittal Article, no further action is required

to Check For A Different or Missing Submittal Item:

  1. In the Section text, locate a Submittal Item and place your cursor between the SUB tags, then perform one of the following:
    1. Right-click and select Check Submittal 
    2. Select the Tools menu and select Check Submittal
  2. When the Submittal Item Not Found window opens, select Yes
  3. In the Submittal Wizard, locate the Show submittals from this submittal list drop-down menu
  4. Select the drop-down arrow and select This Section from the list to verify if the Submittal may be listed in singular or plural form
  5. Below Submittal Description (SD Number), select the appropriate Submittal Description from the list
  6. Below Approval, select a Classification Code and enter a Reviewer, if required
  7. Click OK
