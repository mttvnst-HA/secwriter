This command can also be executed from the SI Editor's Table's Right-click menu.

The Clear Background Color for command provides the capability to clear the background color in a selected column, row, cell, or table. The Formatted Table is activated by clicking in a cell to input new content, formatting, or tagging.

To avoid accidental entry into the cell when is active, use click-and-drag for this action.

 

In the event of an error, click outside the table and use the Undo (Ctrl+Z) command.  To learn more, see the Table Tips and Tricks topic.

How to Use This Feature

To Clear the Background Color In Selected Cells:

The Clear Background Color for option becomes available in the right-click menu only when two or more cells are selected using the click-and-drag method to highlight. If you click without dragging, they will be active.

 

  1. In a Formatted Table, perform one of the following:
    1. Hover over a shaded cell, click-and-drag the cursor to select a cell range, right-click, and select Clear Background Color for, then choose Selected Cells
    2. Click in a shaded cell, select the Table menu, and select Clear Background Color for, then choose Selected Cells 

  1. To save the changes, click outside the table and perform one of the following:
    1. Click the Save button on the Toolbar
    2. Select the File menu and click Save
    3. Use the keyboard shortcut Ctrl+S

To Clear the Background Color In A Cell:

  1. In a Formatted Table, perform one of the following:
    1. Hover over a shaded cell, right-click, and select Clear Background Color for, then select Cell
    2. Click in a shaded cell, select the Table menu, and select Clear Background Color for, then select Cell

  1. To save the changes, click outside the table and perform one of the following:
    1. Click the Save button on the Toolbar
    2. Select the File menu and select Save
    3. Use the keyboard shortcut Ctrl+S
