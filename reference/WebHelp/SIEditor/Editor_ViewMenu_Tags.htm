The Tags view option controls whether tags are displayed in the Editing window. When active, tags are visible, which is crucial for editing. Hiding the tags can help review the SectionA set of files within the Division of a Master or Job that covers specific aspects of construction formatting.

It is crucial to keep tags visible while editing a SectionA set of files within the Division of a Master or Job that covers specific aspects of construction. This practice helps prevent tagging errors and ensures the Section's structural integrity.

How To Use This Feature

To Show or Hide Tags:

  1. In the SI Editor, perform one of the following:
  1. Right-click and select  View Tags
  2. Click the Toggle Tags View button on the Toolbar
  3. Select the View menu and select Tags
  4. Use the keyboard shortcut Alt+S
