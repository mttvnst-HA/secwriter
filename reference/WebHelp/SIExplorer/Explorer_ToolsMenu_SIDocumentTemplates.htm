SI Document Templates are Job-specific blank templates used to create SpecsIntact formatted cover pages,  sign-off sheets, project information sheets, or other unique documents to be used within Jobs since they do not apply to Masters. These functions are designed for creating and editing document templates intended for use across all SpecsIntact Jobs, rather than being restricted to a specific one. For this reason, most of these capabilities remain active even if you have a Master selected in the SpecsIntact Explorer when you perform them.

The SI Document Templates window offers additional functionality through its right-click menu, allowing you to either Rename the template or directly Open it within the Windows File Explorer.

The SI Document Template represents a legacy interface option infrequently used, though remaining accessible for specific requirements.

Click the buttons on the image below to see how to use each function.

  • Add button - Adds the selected SI Document Template to the active Job.
  • New button - Opens the New SI Document Template window. In this window, you can assign a New name and New title to your template, and specify its Working Directory.
  • Edit button - Opens the selected template in the SI Editor, so you can edit and save the template.
  • Copy button - Opens the Copy SI Document Template window, where you can duplicate the selected template by specifying a new Template Name. When doing so, you have the option to either keep the template in its current Working Directory or direct the copy to an alternate one.
  • Delete button - Deletes the selected template.

Standard Windows Commands

The Cancel button will close the window without recording any selections or changes entered.

The Help button will open the Help Topic for this window.
