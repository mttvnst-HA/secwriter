The Copy command allows you to copy and paste Sections or other files from the SpecsIntact Explorer to other Windows applications or from one project to another. Additionally, you can use the standard Windows keyboard shortcuts to Copy (Ctrl+C) and Paste (Ctrl+V). The copied Section(s) will remain in the Windows ClipboardThe Windows Clipboard is a temporary storage location for transferring information. Information is placed in the Clipboard through the cut or copy function and will remain there until you clear the Clipboard, cut or copy another piece of information onto it, or exit Windows until you overwrite them with another Cut or Copy function, or until Windows is shut down.

To learn more about using the drag-and-drop feature to easily add Section(s) from one project to another or drag-and-drop other files, such as exported files, reports, PDF files, or Word files from the SpecsIntact Explorer to other Windows applications like the Windows Desktop, File Explorer, or Outlook messages, refer to the SpecsIntact Explorer Overview > Drag-and-Drop topic.

How To Use This Feature

to Copy Single or Multiple Sections to a Job or Master:

  1. In the SpecsIntact Explorer's Available Projects panel, select the source project
  2. In the Contents panel, select the Section(s) to copy, then perform one of the following:
    1. Select a single Section
    2. Press-and-hold the Shift key to select multiple consecutive Sections
    3. Press-and-hold the Ctrl key to select multiple non-consecutive Sections
  3. Once the Section(s) are highlighted, perform one of the following:
    1. Right-click and select Copy
    2. Select the Sections menu and select Copy
    3. Use the keyboard shortcut Ctrl+C
  4. In the Available Projects panel, select the target Job or Master, then perform one of the following:
    1. Right-click and select Paste
    2. Use the keyboard shortcut Ctrl+V
  5. When the Copy Files window appears, click Yes

To Copy and paste files from SpecsIntact to other applications:

  1. In the SpecsIntact Explorer's Contents panel, select the Section(s) or file(s) to copy, then perform one of the following:
    1. Right-click and select Copy
    2. Select the Sections menu and select Copy
    3. Use the keyboard shortcut Ctrl+C
  2. Navigate to the application to paste your files (e.g., Windows File Explorer, Desktop, or Microsoft Outlook), then perform one of the following:
    1. Right-click and select Paste
    2. Use the keyboard shortcut Ctrl+V
