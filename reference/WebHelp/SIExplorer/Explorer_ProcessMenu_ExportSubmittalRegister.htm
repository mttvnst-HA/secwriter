The generated file(s) will be available within the SpecsIntact Explorer and located in the Job or Master Exports folder.

Format Options

Create Web File

Creates a Web (.htm) file that can be opened with any Web browser (e.g., Microsoft Edge, Chrome, Firefox, etc.) for viewing. It may also be opened with any spreadsheet application for editing if required. The default output file name is UFGS4288.htm and can be opened with a web browser or spreadsheet application.

Create Spreadsheet File

This function will create a spreadsheet file.  The default output file name will be UFGS4288.xlsx and can be opened with a spreadsheet application.  

Create Comma-Delimited File

This file contains the Job or Master's Submittal data in comma-delimited format. The default output file name is UFGS4288.txt and can be opened with Notepad or a spreadsheet application.

The comma-delimited text file is primarily used to import the submittal data into the Army's Resident Management System (RMS).

Single or multiple files can be exported within the same session.  After processing, the exported files will be available within the SpecsIntact Explorer and located in the Job or Master Exported Files folder.

Color for Web and Spreadsheet File

The default color option is 'no color,' though three additional color options are available for customization:

  • Color table header only
  • Color table header and rows, alternating by Section
  • Color table header and rows, alternating every '#' Row(s)

Divider for Web and Spreadsheet File

Inserts a bold horizontal line to visually separate the Sections and enhance readability.

File Name Options

File Name (No Extension)

The file name is automatically generated based on the Job or Master name but can be customized in the provided text field. Microsoft Windows reserved characters to avoid when naming files or folders are the left and right angle brackets, colon, quotation, forward and back slash, pipe symbol, question mark, and asterisks as indicated here:  < > : " / \ | ? *  

The file extension should not be entered, since the software will automatically insert the correct extension based on the selection below Format Options.

E-mail Options

Attach Exported files To E-mail Message When Finished

After the Exported file is generated, this function will create a new e-mail message with the UFGS4288 file(s) attached.

This feature supports MAPI e-mail clients, like Microsoft Outlook or Mozilla Thunderbird.  Web-based e-mail clients that use POP3 and IMAP like Gmail, Yahoo, etc. are not supported.

How to Use this Feature

to Export a Submittal Register:

  1. In the SpecsIntact Explorer, select the desired Job or Master, then perform one of the following:  
    1. Right-click and select Export Submittal Register
    2. Select the Process menu and select Export Submittal Register
  2. In the Export Submittal Register window, below Format Options, select the desired output option(s) (e.g., web, spreadsheet, comma-delimited, or a combination)
  3. Select the applicable color or divider options (these options are optional)
  4. Click OK
  5. On the confirmation window, click OK

to Export and E-mail an Exported Submittal Register:

  1. In the SpecsIntact Explorer, select the desired Job or Master, then perform one of the following:  
    1. Right-click and select Export Submittal Register
    2. Select the Process menu and select Export Submittal Register
  2. In the Export Submittal Register window, below Format Options, select the desired output option(s) (e.g., web, spreadsheet, comma-delimited, or a combination)
  3. Select the applicable color or divider options (these options are optional)
  4. Below E-mail Options, select Attach exported files to e-mail message when finished
  5. Click OK
  6. On the confirmation window, click OK
  7. When the e-mail message opens, add recipient(s) and a message
  8. Click Send
