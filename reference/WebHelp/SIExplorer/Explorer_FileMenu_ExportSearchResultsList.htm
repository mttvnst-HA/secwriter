This command can also be executed from the SpecsIntact Explorer's Right-click menu.

The Export Search Results command provides the functionality to export the outcome of the most recently executed search operation on the selected JobA specific facility construction project that consists of a group of guide specifications (Section (.sec) files) that are adapted to the project or MasterA group of standard Government agency (Master) Guide Specifications used in the preparation of a Job.

The search results are temporarily stored in a Result Files folder. This folder is created inside either the  Jobs or  Masters folder, located at the bottom of your project folder list.

You must navigate to the temporary Result Files folder to execute the Export Search Results command. 

This temporary Result Files folder exists only while SpecsIntact is open and will be removed when you close the application.

Executing the Export Search Results command from here will create a file named 'SearchResults.htm'. This export file will be located in the Jobs or Masters Exports folder within SpecsIntact Explorer. To keep a copy of the exported search results and prevent them from being overwritten by subsequent searches, make sure to rename the file to give it a unique, identifiable name (e.g., SearchResults - Contractor.htm) immediately after exporting. The generated exported files can be accessed through your preferred web browser, Microsoft Excel, or shared through email.

The files within the temporary Results Files folder are your active working files. Do not delete them directly from this folder to prevent data loss.

How To Use This Feature

to Export the Search Results List:

Step 1:  Perform a Search:

  1. In the SpecsIntact Explorer, select the Job or Master to search, then perform the following:
    1. Right-click and select Search and Replace
    2. Select the File menu and select Search and Replace
    3. Use the keyboard shortcut Ctrl+F
  2. When the Search and Replace window appears, place your cursor in the Search box and type the search term
  3. In the Search Options, select the option(s) to perform the search
  4. Click the Search button
  5. When the Occurrences Found window appears, review the detailed information and click OK

Step 2:  Export the Search Results List:

  1. Following the Search (Step 1: noted above), perform one of the following:
    1. Right-click on the Result Files folder and select Export Search Results 
    2. Select the File menu and select Export Search Results
  2. In the Specify File Name for Search Results window, navigate to the File name field, then perform one of the following:
    1. Use the existing filename
    2. Enter a new filename to give it a unique, identifiable name (e.g., SearchResults - Contractor.htm)
  3. Click Save
  4. On the Export Search Results window, click OK
