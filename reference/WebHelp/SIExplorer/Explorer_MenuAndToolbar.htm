The Menu Bar and Toolbar are core components of the SpecsIntact Explorer, each playing an important role in how you interact with the software. While both provide access to commands and functions, they differ in their organization, presentation, and primary usage. 

The Menu Bar is typically found at the top of the application window and offers a deep, organized structure for all commands, whereas the Toolbar is directly below the Menu Bar and provides visual, graphical buttons for more immediate access to frequently used functions, optimized for efficiency.

menu Bar

The Menu Bar provides access to all application-specific functions through its drop-down menus. Selecting a menu item will display not only the available commands but also their associated keyboard shortcut. Commands followed by an ellipsis (e.g., "Properties...") indicate that more options will appear.

Toolbar

The Toolbar provides shortcuts to some of the most common functions you will use when managing your Jobs or Masters. If you want to declutter your workspace, you can easily hide the Toolbar button text labels. To do this, go to the Setup menu > Options > General tab, under Selectable Options, and select the Hide text on menu buttons to display more content on main window.
