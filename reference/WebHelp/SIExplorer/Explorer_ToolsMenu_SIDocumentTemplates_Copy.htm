This command can only be executed from the SI Explorer's SI Document Templates menu. 

The Copy button allows you to duplicate the selected SI Document Template. You can then use this copy as a standalone duplicate or as a guideline for creating a new custom template. This process involves assigning a new name and using the current Working Directory, or assigning a new one.

Although the SI Document Templates are accessible from Masters, these functions are specifically designed for managing templates across all SpecsIntact Jobs. So, they will remain accessible even when a Master is selected.

The SI Document Template represents a legacy interface option infrequently used, though remaining accessible for specific requirements.

  • Template Name - Identifies the template in the SpecsIntact Explorer and Windows File Explorer and may contain up to 50 letters and numbers with no special characters.
  • Copy to Working Directory - Provides the option to copy a Section Template to a Working Directory.
    • Working Directory - Provides the option to leave the displayed default Working Directory or select a different one from the drop-down list.
  • Copy to Master - This option is disabled since SI Document templates are Job-specific and do not apply to Masters.
    • Master - This option is disabled since SI Document templates are Job-specific and do not apply to Masters.

Standard Windows Commands

The OK button will execute and save the selections made.

The Cancel button will close the window without recording any selections or changes entered.

The Help button will open the Help Topic for this window.

How To Use This Feature

To Copy an SI Document Template to a Job:

  1. In the SpecsIntact Explorer, select the Tools menu and select SI Document Templates
  2. In the SI Document Templates window, select a template in the list and click Copy
  3. In the Copy SI Document Template window, enter a new name into the Template Name field
  4. In the Working Directory field, perform one of the following:
    1. Use the current Working Directory
    2. Select the drop-down arrow and select a different Working Directory from the list
  5. Click OK
