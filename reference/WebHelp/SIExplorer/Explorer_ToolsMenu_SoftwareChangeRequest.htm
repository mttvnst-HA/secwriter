SI Explorer Tools Menu - Software Change Request 

In this Topic HideIn this Topic Show
  1. Technical Support Information

This command can only be executed from the SpecsIntact Explorer's Tools menu.

The Software Change Request command is a versatile tool for managing software-related enhancements and issues. by providing the options to request new features or improvements to the existing software, or submit problems encountered on the current system or another system.  Beyond these core functions, you can also save, delete, or print these forms for future reference.
