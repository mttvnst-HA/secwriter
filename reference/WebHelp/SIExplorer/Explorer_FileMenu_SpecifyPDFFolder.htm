This command can also be executed from the SpecsIntact Explorer's Right-click menu.

The Specify PDF Folder command controls where the Job or Master PDF files are saved. Even when saved externally, the PDF files will remain displayed in the SpecsIntact Explorer under the PDF Files folder for the respective Job or Master, identifiable by their dark red  PDF file icon, provided you select YES when prompted to move the files.

To access your PDF files directly from the SpecsIntact Explorer, right-click on the PDF Files folder and select Open in Windows Explorer. You'll find the PDF files located within the project's prntdata folder.

Before making significant changes to a Job or Master, it's always recommended to create a backup first. You can do this easily by going to the File menu > Backup and Restore.

Instead of using the Specify PDF Folder command to move your PDF files outside the Working Directory, you might consider an alternative approach using the File menu > Process and Print Publish > PDF Publish tab. Within this tab, you'll find the Save copies to this folder option. This allows you to save duplicates of your PDF files to a different location, all while ensuring the original PDFs remain with your project.

How To Use This Feature

to Designate A New PDF Folder:

  1. In the SpecsIntact Explorer, select the Job or Master, then perform one of the following:
    1. Right-click and select Specify PDF Folder
    2. Select the File menu and select Specify PDF Folder
  2. In the Select Folder window, perform one of the following:
    1. Browse and select a folder
    2. Create and select a new folder
  3. Click Select Folder 
  4. On the Move Existing Files window, click Yes
  5. On the New File Location window, click OK
