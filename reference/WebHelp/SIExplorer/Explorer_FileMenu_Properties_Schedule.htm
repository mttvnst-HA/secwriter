The Schedule tab provides the flexibility to refine and update any pertinent information related to the selected Job. This ensures that all details remain current by tracking throughout the Job lifecycle, after the initial creation. This includes the recording of the Job's Review Status / Amendment Level, the Next due date, and the Job Cycle. 

The available options in SpecsIntact vary between Jobs and Masters, reflecting their distinct purposes and requirements. The Cover Page and Schedule tabs are exclusively available within Jobs.

Click the tabbed commands on the image below to see how to use each function.

  • Review Status / Amendment Level - Provides options to track and manage the design level of a project. This information is used to automatically generate the Job's PDF Files folders created when publishing the Job by organizing the PDF files in the appropriate Review Status (e.g., 35%, 65%, 95%) or Amendment Level (e.g., A, B, C, etc.) folders.
  • Next due date - Provides the flexibility to set the project's due date, which is an important component for project management, ensuring that all team members are aware of the final deadline.
  • Job Cycle - Provides the options to meticulously track each stage of your project. Here you can record essential details like the operator, status level, received date, due date, delivered date, and optionally record the hours.

Standard Windows Commands

The OK button will execute and save the selections made.

The Cancel button will close the dialog box without recording any selections or changes entered.

The Help button will open the Help Topic for this dialog box.

How To Use This Feature

To Track and Manage Job Schedules:

  1. In the SpecsIntact Explorer, select a Job, then perform one of the following:
    1. Right-click and select Properties, then select the Schedule tab
    2. Click the Properties button on the Toolbar, then select the Schedule tab 
    3. Select the File menu, select Properties, then select the Schedule tab 
  2. On the Schedule tab, below the Review Status / Amendment Level, perform one of the following:
    1. Select the drop-down arrow and select NONE, 30%, 60%, 90%, FINAL, or BID
    2. Place your cursor in the field and enter a custom status (e.g., 35%, 65%, 95%) or Amendment Level (e.g., A, B, C, etc.)
  3. In the Next due date field, perform one of the following:
    1. Enter the date in MM/DD/YY format
    2. Click the Calendar button and select a date
  4. Below the Job Cycle, perform the following:
    1. Double-click in the Operator field and enter the operator's name
    2. Double-click in the % field and enter the applicable Review Status or Amendment Level
    3. Double-click in the Received field, enter the date in MM/DD/YY format, or click the Calendar button and select a date
    4. Double-click in the Due field, enter the date in MM/DD/YY format, or click the Calendar button and select a date
    5. Double-click in the Delivered field, enter the date in MM/DD/YY format, or click the Calendar button and select a date
    6. Double-click in the Hours field, and enter the number of hours
  5. Click OK
