The Supplemental References tab provides an automated option for managing the Supplemental List, Supplemental Address List,A custom file maintained by the user to include reference publications beyond those found in the UFGS Master guide specifications or Supplemental Reference ListA custom file maintained by the user to include reference standards not found in the UFGS Master guide specifications within the selected project. Once generated, you can easily edit the existing supplemental lists or even print its entire contents for a complete overview.

The available options in SpecsIntact differ between Jobs and Masters, reflecting their distinct purposes and requirements. The Master Reference List tab is unique to Masters.

Before making significant changes to the Supplemental Lists, it's always recommended to create a backup first. You can do this easily by going to the File menu > Backup and Restore.

Supplemental Address List

Jobs:

The Supplemental Address List streamlines the automatic inclusion of local, county, and state Reference addresses within UFGS 01 42 00 Sources for Reference Publications, upon the creation of new Jobs. SpecsIntact will automatically populate UFGS 01 42 00 with addresses for local Reference-issuing organizations stored in the Supplemental Address List when new Jobs are created from the UFGS.

SpecsIntact merges the Reference-issuing organizations from the Supplemental Address List into the Job's 01 42 00 Section when new Jobs are created.

To effectively utilize the Supplemental Address List feature for Jobs, it is imperative to update the Supplemental Address List prior to creating a new Job. Following Job creation, any local (e.g., county or state) Reference-issuing organizations, including their corresponding information, should first be added to the Supplemental Address List. Subsequently, the Reference Organization can be copied and manually inserted into the current Jobs 01 42 00 Sources for Reference Publications Section. This two-step process for new local Reference-issuing organizations guarantees the accuracy of information for the current Job and any subsequent new Jobs. 

Masters:

SpecsIntact offers the flexibility to create a new Supplemental Address List either as an empty list for manual additions or from any local Master whose 01 42 00 Sources for Reference Publications Section contains addresses for local (e.g., county or state) Reference-issuing organizations. To avoid duplicate addresses, the list should be created from a Master Section where organization addresses are alphabetized by organization name, consistent with the UFGS 01 42 00 Section.

Supplemental Reference List

The Supplemental Reference List is designed for user-specific requirements to facilitate compiling a custom set of References, specifically for standards not incorporated within the UFGS Master Sections. Maintaining the Supplemental Reference List eliminates the need to manually add the Reference-related information into the Section's Reference Articles. 

SpecsIntact streamlines the integration of References within project specifications. This automation, driven by a dedicated set of tags, populates and reconciles References within both the Reference Articles and the Supplemental Reference List. This ensures that only actively cited publications are included during processing, provided all information is accurately tagged. Upon initiation of the Reference Reconciliation process, the software identifies all References absent from the Section's Reference Articles. It then scans the Supplemental Reference List from which the missing References are extracted and subsequently incorporated into the Section's Reference Articles. This reconciliation is exclusively viewable in the Processed (.prn) files or PDF documents, not within the Section (.sec) files.

Click the tabbed commands on the image below to see how to use each function.  

  

  • Supplemental List - Displays the active Supplemental List featuring a drop-down to readily switch between the available Supplemental Address List or Supplemental Reference List for a Job or local Master.
  • Action - Provides the option to generate, manage, and print a list of addresses or References used throughout the project's Sections. The supplemental lists are primarily used for Jobs or local Masters.
    • Generate new list - Generates a new list from the source chosen from the Master Reference File to Use. Its primary application applies to Jobs or local Masters, where it facilitates the compilation of a new or empty list from a designated source within the selected source. It is important to note that initiating this function will overwrite any previously existing list.
    • Edit list - Allows you to edit an existing Supplemental Address List or Supplemental Reference List through the SI Editor to keep the Reference-issuing organizations current.
    • Print list - Opens the Print Setup window so you can select a printer and Supplemental Reference List that displays an all-inclusive export of your project's data, compiling information from each tab into one cohesive document. It offers a detailed summary of the entire project.
  • Supplemental references folder - Displays the location of the existing Supplemental Lists.
    • Change button - Opens the Windows File Explorer to navigate and select a different location for your Supplemental Lists.
  • Master Reference File to Use - Displays the available Master Reference List(s) used to generate a Supplemental Reference List.
  • Path - Displays the file location of either the Master 01 42 00 Section used for the Supplemental Address List or the Supplemental Reference List.

How To Use This Feature

To Generate a Supplemental Address or Reference List:

  1. In the SpecsIntact Explorer, select a Job or Master and select the Process menu, then select Reference Processing
  2. In the Reference Processing window, select the Supplemental References tab
  3. Below the Supplemental List, perform one of the following:
    1. Leave the default Supplemental Address List selected
    2. Select the drop-down arrow, then select the Supplemental Reference List
  4. Below Action, select Generate new list
  5. In the Master Reference File to Use, perform one of the following:
    1. Select [none] to create an empty List
      1. On the Empty Supplemental Address List Created window, click OK
    2. Select one of the available Masters, then click OK
      1. On the Master Needs Local Reference Addresses window, select Continue using Master
      2. On the Remove Duplicate Addresses Already in UFGS window, perform one of the following:
        1. Select Remove duplicate addresses (recommended)
        2. Select Include duplicates
      3. On the Supplemental Address List Created window, click OK
      4. When the Supplemental Address/Reference List Created window appears, click OK 
  6. When returned to the Supplemental References tab, click Close

To Edit a Supplemental Address or Reference List:

  1. In the SpecsIntact Explorer, select a Job or Master and select the Process menu, then select Reference Processing
  2. In the Reference Processing window, select the Supplemental References tab
  3. Below the Supplemental List, perform one of the following:
    1. Leave the default Supplemental Address List selected
    2. Select the drop-down arrow, then select the Supplemental Reference List
  4. Below Action, select Edit list
  5. Click OK
  6. When the Supplemental Address List (suppaddr.ref) file opens in the SI Editor, make the necessary changes, then save and close the file
  7. Click Close
