This command can also be executed from the SpecsIntact Explorer's Right-click menu.

The Renumber command is used for updating the numbering of Sections within a Master that uses the legacy Traditional Paragraph Numbering. This process ensures the synchronization of Subpart numbers embedded in Subpart tags with those in the Subpart Titles so they reflect the same number. This operation results in permanent modifications to the actual Section (.sec) files, not the Processed (.prn) files.

To learn about converting a Master to use the Automatic Paragraph Numbering, refer to the Process menu > Convert to Automatic Numbering topic.

How To Use This Feature

to Renumber One or More Sections:

  1. In the SpecsIntact Explorer, select a Master
  2. In the Contents panel, perform one of the following:
    1. Select a Section
    2. Press-and-hold the Shift key to select multiple consecutive Sections
    3. Press-and-hold the Ctrl key to select multiple non-consecutive Sections
  3. Once the Section(s) are highlighted, perform one of the following:
    1. Right-click and select Renumber
    2. Select the Sections menu and select Renumber
  4. On the Confirm Selections to Renumber window, perform one of the following:
    1. Leave all Sections selected
    2. Deselect the Sections you do not want to change
  5. On the Sections Renumbered window, click OK
