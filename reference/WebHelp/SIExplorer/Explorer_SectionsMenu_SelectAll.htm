This command can also be executed from the SpecsIntact Explorer's Right-click menu or by using the keyboard shortcut Ctrl+A.

The Select All command provides a quick way to select all the files displayed in the SpecsIntact Explorer's Contents panel.  This functionality is particularly beneficial when using the copy-and-paste or drag-and-drop actions from the SpecsIntact Explorer to other Windows applications, such as the Windows Desktop, File Explorer, or Outlook messages.

To reverse the Select All command, refer to the Sections menu > Unselect All topic.

You also have the option to highlight either consecutive or non-consecutive Sections. To select consecutive Sections, press-and-hold the Shift key, and to select non-consecutive Sections, press-and-hold the Ctrl key instead.

How To Use This Feature

To Select All Sections:

  1. In the SpecsIntact Explorer, select a Job or Master
  2. In the Contents panel, select a Section, then perform one of the following:
    1. Right-click and choose Select All
    2. Select the Sections menu and choose Select All
    3. Use the keyboard shortcut Ctrl+A
