This command can only be executed from the SpecsIntact Explorer's Right-click menu.

The Icon Color feature in the SpecsIntact Explorer offers extensive personalization options for folder and file icons by assigning new colors to the main Jobs and Masters folders and various file types. Changing the color of the main Jobs or Masters folders applies that color to all Jobs and Masters system-wide. You have the flexibility to select pre-defined colors, choose colors from an extensive palette of colors, or create custom colors to distinguish these elements visually within the SpecsIntact Explorer.

How To Use This Feature

To Change An Icon Color:

  1. In the SpecsIntact Explorer, right-click on a folder or file, then perform one of the following:
    1. Select Jobs Icon Color
    2. Select Masters Icon Color
    3. Select Icon Color for Files 
  2. In the Color sub menu, select one of the following:
    1. Select Default
    2. Select one of the available color options

 To Create a Custom Icon Color:

  1. In the SpecsIntact Explorer, right-click on a folder or file, then perform one of the following:
    1. Select Jobs Icon Color
    2. Select Masters Icon Color
    3. Select Icon Color for Files 
  2. In the Color sub menu, select Custom Colors, and click the drop-down arrow, then perform one of the following:
    1. Select the Standard tab, then select one of the available colors
    2. Select the Advanced tab, then perform one of the following:
      1. Use the Color Slider Bar to change the color
      2. Enter the Hex Color value in the field (e.g., #2d5986)
      3. Enter the RGBA values in the fields

To Reset all Icon Colors To Their Default Color:

  1. In the SpecsIntact Explorer, select Setup and select Reset Settings
  2. Below Settings to Reset, select Icon colors
  3. Click OK
