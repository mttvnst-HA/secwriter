This command can also be executed from the SpecsIntact Explorer's Right-click menu.

The E-mail command allows you to select files from the SpecsIntact Explorer's Contents panel and attach them to an e-mail.  This function works with your system's default desktop e-mail client, such as Microsoft Outlook, Mozilla Thunderbird, etc.  By default, the e-mail is addressed to SpecsIntact@usace.army.mil to request assistance, but this address can be replaced with other recipients.

This feature is designed for use with installed desktop email clients like Microsoft Outlook and will not work with web-based email services like Gmail, Yahoo Mail, Hotmail, etc.

To learn more about using the drag-and-drop feature to easily add Section(s) to other Windows applications like the Windows Desktop, File Explorer, or Outlook messages, refer to the SpecsIntact Explorer Overview > Drag-and-Drop topic.

How To Use This Feature

to E-mail One or more Sections:

  1. In the SpecsIntact Explorer, select the Job or Master
  2. In the Contents panel, perform one of the following:
    1. Select a Section
    2. Press-and-hold the Shift key to select multiple consecutive Sections
    3. Press-and-hold the Ctrl key to select multiple non-consecutive Sections
  3. Once the Section(s) are highlighted, perform one of the following:
    1. Right-click and select E-mail
    2. Select the Sections menu and select E-mail
  4. When the e-mail window opens, the Section(s) will be automatically attached. You can then make any necessary modifications to the recipients and subject line
  5. When finished, click Send
