This command can also be executed from the SpecsIntact Explorer's Sections menu.

The Remove Tailoring Tags command provides the option to remove all Tailoring (TAI) tags, but not their content, from the selected Job. 

Before this option is available, your Job Review Status / Amendment Level must be set to FINAL or BID. For more information, refer to the SpecsIntact Explorer's File menu > Properties > Schedule topic.

Remember, ONLY remove Tailoring tags if you no longer need to edit this project. You will be unable to tailor your project further.

When the Confirm Selections for Removing Tailoring Tags window appears, you can either remove all Tailoring (TAI) tags from all the Sections or deselect Sections to keep them unchanged.

Before making significant changes to a Job, it's always recommended to create a backup first. You are prompted and have the option to perform a backup before proceeding, or you can do this by going to the File menu > Backup and Restore.

To Remove Tailoring Tags from pre-selected Sections in the SpecsIntact Explorer, refer to the Sections menu > Remove Tailoring Tags topic.

The Tailoring Options item in the SI Editor > View menu is grayed out when you open a Section that all Tailoring tags have been removed.

Standard Windows Commands

The OK button will execute and save the selections made.

The Cancel button will close the window without recording any selections or changes entered.

The Help button will open the Help Topic for this window.

How To Use This Feature

to Remove Tailoring Tags from a Job:

  1. In the SpecsIntact Explorer, select a Job, then select the File menu and select Remove Tailoring Tags
  2. On the Back Up Project window, perform one of the following:
    1. Select Backup, to backup the project before removing Tailoring tags (preferred)
    2. Select Remove Tailoring tags from Job without backing up
    3. Select Cancel
  3. On the Confirm Selections for Removing Tailoring Tags window, perform one of the following:
    1. Leave all Sections selected
    2. Deselect the Sections you don't want to change
  4. Click OK
  5. When the No Tailoring Tags Removed window or Tailoring Tags Removed window appears, click OK
