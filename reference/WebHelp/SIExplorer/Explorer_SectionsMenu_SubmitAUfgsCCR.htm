This command can also be executed from the SpecsIntact Explorer's Tools menu, Right-click menu, or the SI Editor's Help menu.

The Submit a UFGS CCR command opens the National Institute of Building Sciences (NIBS) Whole Building Design Guides (WBDG) Website UFGS Management CCR page for the selected Section. This page enables the formal submission of a Criteria Change Request (CCR) for UFGS-related issues not directly attributable to the software. This form should be utilized to provide comments, suggestions, and recommended changes for review by the assigned technical proponent. The technical proponent will contact the submitter directly if further communication is required.

How To Use This Feature

to Submit A Criteria Change Request (CCR) For A Section:

  1. In the SpecsIntact Explorer, select a Job or Master
  2. In the Contents panel, select a Section, then perform one of the following:
    1. Right-click and select Submit a UFGS CCR
    2. Select the Sections menu and select Submit a UFGS CCR
    3. Select the Tools menu and select Submit a UFGS CCR
  3. Once the UFGS Management CCR page opens, fill out the form and complete the Security Question
  4. Click Submit
