This command can only be executed from the SpecsIntact Explorer's Process menu.

The Convert to Automatic Paragraph Numbering command is a tool that converts the paragraph numbering in older projects, which use the legacy Traditional Paragraph Numbering, to the Automatic Paragraph Numbering system, utilizing either current numeric numbers or alphanumeric numbers.

Upon execution, the traditional legacy numbering will be replaced by the automatic numbering. 

The conversion process will remove the paragraph numbers and three spaces from all Subpart (SPT) titles throughout the Sections.  Once this is done, SpecsIntact will designate the Section as requiring automatic numbering by inserting a Meta Data (MTA) tag at the top of each SectionA set of files within the Division of a Master or Job that covers specific aspects of construction.  After completion, SpecsIntact automatically numbers the subparts for the Sections during editing, printing, and publishing.  Please note that Part (PRT) tags and titles are consistently the same and will retain the traditional legacy format. After conversion, the Subpart tags and titles will always be synchronized. Additionally, the Conversion Log (SIAutoConvertLog.txt) file is automatically saved in the project's Exported Files folder.

After conversion, the files within the temporary Results Files folder are your active working files. Do not delete them directly from this folder to prevent data loss.

Before making significant changes to a Job or Master, it's always recommended to create a backup first. You can do this easily by going to the File menu > Backup and Restore.

To learn more about Automatic Paragraph Numbering, refer to the Automatic Paragraph Numbering topic.

For backward compatibility, SpecsIntact will continue to support the traditional legacy paragraph numbers.

How To Use This Feature

to convert a Job or Master to Automatic Paragraph Numbering:

  1. In the SpecsIntact Explorer, select a Job or Master, then press F5 to refresh the Available Projects panel to ensure focus is on the selected project
  2. Select the Process menu, and select Convert to Automatic Paragraph Numbering
  3. When the Back Up Project window appears, perform one of the following:
    1. Select Backup, to backup the project before conversion
      1. When the Backup and Restore window appears, click OK
      2. On the Backup File Created window, click OK
      3. Once the backup is complete, the Convert to Automatic Paragraph Numbering initiates automatically
    2. Select Convert Sections to automatic paragraph numbering
  4. In the Confirm Selections window, perform one of the following:
    1. Leave the default selections
    2. Select to unhighlight the Sections to leave unchanged
  5. Click OK
  6. On the Sections Converted window, click OK
