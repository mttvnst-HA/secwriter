Reference Reconciliation 

In this Topic HideIn this Topic Show
  1. Additional Learning Tools
  2. Technical Support Information

Reference Reconciliation is a crucial process designed to ensure the accuracy and consistency of all References within your Job's specifications. It automatically verifies and updates References, streamlining your workflow and preventing discrepancies. This process changes the Reference ArticleAn Article within Part 1 that contains a list of the Publishing Organizations and the titles of all technical references used in the section text of each Section so that it lists only those References that are cited in the Section's text.  References used within the text and not found in either the Section's Reference Article or the Supplemental Reference ListA custom file maintained by the user to include reference standards not found in the UFGS Master guide specifications will appear in the Reference Verification Report results.

To get correct results, you can select All Sections or Some Sections and verify that the References are selected when you print or publish.

These modifications affect only the Processed (.prn) files, not the original Section (.sec) files. Each new Processed (*.prn) file overwrites the previous one.
