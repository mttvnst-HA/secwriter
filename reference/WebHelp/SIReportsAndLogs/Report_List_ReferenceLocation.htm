Reference Location List 

In this Topic HideIn this Topic Show
  1. Technical Support Information

The Reference Location List Report is an invaluable tool that provides a detailed accounting of every instance a Reference is cited throughout your Job or Master. This feature helps you quickly locate where each reference is used, ensuring accuracy, consistency, and easy navigation within your project.

The Reference Location List Report (REFKYLST.RPT) includes all the References cited in the Job, followed by the Sections and Subpart Numbers where they can be found.

To learn how to insert and manage References, refer to the Reference Wizard Overview topic.
