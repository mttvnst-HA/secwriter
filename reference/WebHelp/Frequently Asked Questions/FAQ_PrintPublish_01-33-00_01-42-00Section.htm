FAQs, Troubleshooting, and Technical Notes

How can I Print only a reconciled 01 33 00 submittal procedures or 01 42 00 sources for reference publication section without printing the whole job?

To ensure accuracy and proper reconciliation, it is essential to process the entire Job before printing the 01 33 00 Submittal Procedures or 01 42 00 Sources for Reference Publications Sections. This action reconciles all elements across your entire Job, ensuring that when you later print these specific Sections, they reflect all necessary updates and cross-references.  Printing these two Sections alone, you will not produce reconciled Sections. The changes made during reconciliation will only appear in the output files (e.g., .prn, .docx, and .pdf), not the original Section (.sec) file.

Reference and Address Reconciliation

This process changes the Job's Reference Article of each Section so that it lists only those References that are cited in the Section's text. 

The Address Reconciliation process should be used in conjunction with Reference Reconciliation. 

  • Reference Reconciliation: Streamlines each Section's Reference Article by ensuring it only lists the references cited within that Section's text.
  • Reference Address Reconciliation: Modifies the Job's 01 42 00 Sources for Reference Publications Section, making it a unique Job-specific list containing only the Sponsoring Organizations associated with references cited across the entire Job.

Submittal Reconciliation

This process changes the Job's 01 33 00 Submittal Procedures Section, making it unique to the Job by listing only the Submittal Descriptions (SD 01 - 11) used throughout the Job.

Symptoms of printing the section before processing against the job

  • When you print the 01 33 00 Section alone, SD-02 through SD-11 are stripped from the output (.prn, .docx, and .pdf) files.
  • When you print the 01 42 00 Section alone, all the Reference Publications are stripped from the output (.prn, .docx, and .pdf) files.

 Step 1: Process the Job

  1. In the SpecsIntact Explorer, select a Job, then perform one of the following:
    1. Right-click and select Process & Print/Publish
    2. Click the Print/Publish button on the Toolbar
    3. Select the File menu and select Process & Print/Publish
    4. Use the keyboard shortcut Ctrl+P
  2. In the Print Processing window, select the Sections tab
  3. Below Select Sections, select All Sections, then click the Process Only button
  4. When publishing to PDF and the Will Not Create PDF Files window appears, click the Process Only button

 Step 2: print the 01 33 00 or 01 42 00 Section

  1. In the SpecsIntact Explorer, navigate to the Job's Processed Files folder within the Available Projects panel
  2. In the Contents panel, select the 01 33 00 or 01 42 00 Section, then perform one of the following:
    1. Right-click and select Print or Publish
    2. Click the Print/Publish button on the Toolbar
    3. Select the File menu and select Print or Publish
    4. Use the keyboard shortcut Ctrl+P
  3.  On the Print Processing window, click the Print button (if printing a hard copy) or the Publish button (if printing to PDF).
