How Do I modify the tailoring options in a master specification?

SpecsIntact offers an easy method for modifying an existing Tailoring (TAI) tag within a Master specification by replacing the Tailoring names without deleting or reinserting the Tailoring (TAI) tags, which can be a very difficult process.

Step 1: Locate Specific Tailoring Options

This step streamlines navigation, allowing you to quickly locate specific Tailoring Options within a Section.

  1. In the SpecsIntact Explorer, select a Master 
  2. In the Contents panel, select a Section, then perform one of the following:
    1. Right-click and select Edit
    2. Double-click on the Section to open it
    3. Select the Sections menu and select Edit
    4. Use the keyboard shortcut Ctrl+E
  3. In the SI Editor, perform one of the following:
    1. Click the Find Tags button on the Toolbar
    2. Select the Edit menu and select Find Tags
    3. Use the keyboard shortcut F4
  4. In the Find Tags window, below Select Tag to Find, perform one of the following:
    1. In the Name field, type 'T' until Tailoring Options appears
    2. Select the drop-down arrow and select Tailoring Options
  5. Below Find, select Begin tags
  6. Below Attribute, check Find tags only with the following attribute value
  7. In the Attribute field, type the attribute name exactly how it appears in the Tailoring tag (e.g., DESIGN-BUILD)
  8. Below Search, select Entire file
  9. Click OK

 Step 2: Add Or modify tailoring options

This series of steps will allow you to insert, add, or correct a Tailoring Option name to the existing Tailoring (TAI) tag.

  1. In the SI Editor, place your cursor after the beginning Tailoring (TAI) tag (e.g., <TAI OPT=XXXX>)
  2. Right-click, select Attributes, and select Tailoring, then select Add Option
  3. On the Add Tailoring Options window, enter the new or correct Tailoring Option name
  4. Click OK

Step 3: delete incorrect tailoring option names

This series of steps will allow you to delete one or more Tailoring Option names within a Tailoring tag.

  1. In the SI Editor, place your cursor after the beginning Tailoring (TAI) tag (e.g., <TAI OPT=XXXX>)
  2. Right-click, select Attributes, and select Tailoring, then select Delete Option
  3. On the Remove Tailoring Options window, select the name to delete
  4. Click OK
