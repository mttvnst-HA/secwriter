How Can I Change The Default Color for brackets?

The SI Editor treats brackets as regular text, making it difficult to differentiate between editing the specification in a Section (.sec) file, a printed or electronic copy, such as a Microsoft Word document or PDF. To avoid confusion, always use the SI Editor's Bracket Replacement feature when editing within the program.

To make brackets more visible, you can choose between two methods, both compatible with any editing style: applying the Highlight (HLS) tag or the Bold (BLD) tag.

Method 1: Preferred method for color printers and on-screen editing

This method involves using the SI Editor's Replace command to apply the Highlight (HLS) tag around your brackets. This tag's attributes will automatically change the bracket color from black to orange.

This method requires applying the change to each Section individually.

Examples

  • Example without tags: [supplement]
  • Example with tags: <HLS>[</HLS>supplement<HLS>]</HLS>

Steps:

  1. In the SpecsIntact Explorer, open a Section
  2. In the SI Editor, temporarily turn revisions off by performing one of the following:
    1. Click the Revisions button on the Toolbar
    2. Select the View menu and select Revisions
    3. Use the keyboard shortcut Alt+R
  3. To use Replace, perform one of the following:
    1. Click the Replace button on the Toolbar
    2. Select the Edit menu and select Replace
    3. Use the keyboard shortcut Ctrl+R
  4. In the Replace window, perform the following:
    1. Place your cursor in the Search For field and enter an opening bracket [
    2. Place your cursor in the Replace With field and enter <HLS>[</HLS>
  5. Below Options, verify Confirm Changes is deselected
  6. Below Search, verify Entire File is selected
  7. Click Change All
  8. When the Replace window appears, click OK
  9. Repeat steps 3 - 7 to replace the closing bracket ]
  10. Repeat step 2 to turn revisions on

Remove Highlight (HLS) Tags

Steps:

  1. In the SpecsIntact Explorer, select a Job or Section(s), then perform one of the following:
    1. Right-click and select Remove Change/Highlight Tags
    2. Select the File menu and select Remove Change/Highlight Tags
  2. On the Confirm Selections for Removing CHG/HLS Tags window, perform one of the following:
    1. Leave all Sections selected
    2. Select to unhighlight Sections to leave the unselected Sections unchanged
  3. Below Tags to Remove, select Highlight [HLS]
  4. Click OK and select one of the following:
    1. On the HLS Tags Removed window (indicating HLS tags were detected), click OK
    2. On the No HLS Tags Removed window (indicating no HLS tags were detected), click OK

Method 2: Preferred Method For Black and white printers

This method involves using the SI Editor's Replace function to apply the Bold (BLD) tag around your brackets. This tag's attributes will automatically change the bracket color from black to bold.

Examples

  • Example without tags: [supplement]
  • Example with tags: <BLD>[</BLD>supplement<BLD>]</BLD>

Steps:

  1. In the SpecsIntact Explorer, open a Section
  2. In the SI Editor, temporarily turn revisions off by performing one of the following:
    1. Click the Revisions button on the Toolbar
    2. Select the View menu and select Revisions
    3. Use the keyboard shortcut Alt+R
  3. To use Replace, perform one of the following:
    1. Click the Replace button on the Toolbar
    2. Select the Edit menu and select Replace
    3. Use the keyboard shortcut Ctrl+R
  4. In the Replace window, perform the following:
    1. Place your cursor in the Search For field and enter an opening bracket [
    2. Place your cursor in the Replace With field and enter <BLD>[</BLD>
  5. Below Options, verify Confirm Changes is deselected
  6. Below Search, verify Entire File is selected
  7. Click Change All
  8. When the Replace window appears, click OK
  9. Repeat steps 3 - 7 to replace the closing bracket ]
  10. Repeat step 2 to turn revisions on

Currently, there isn't a global function to remove Bold (BLD) tags. To reverse these changes, you'll need to use the SI Editor's Edit menu > Replace command.
