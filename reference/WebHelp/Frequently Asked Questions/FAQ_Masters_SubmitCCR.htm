How do i submit changes for a UFGS Specification?

All changes to UFGS specifications, whether technical or related to formatting, must be submitted through the UFGS Criteria Change Request (CCR) system. This system is managed by the National Institute of Building Sciences (NIBS) Whole Building Design Guide (WBDG). You can easily submit Criteria Change Requests (CCRs) directly through SpecsIntact, which simplifies the entire process. This integration means you do not have to use external methods, making your workflow more efficient.

The Technical Proponent for the specification will review all UFGS CCR submissions and issue a status, regardless of the submission method.

Method 1: submit a UFGS CCR From SpecsIntact

SpecsIntact Explorer: 

  1. In the SpecsIntact Explorer, select a Job or Master
  2. In the Contents panel, select a Section, then perform one of the following:
    1. Right-click and select Submit UFGS CCR
    2. Select the Sections menu and select Submit UFGS CCR
    3. Select the Tools menu and select Submit UFGS CCR
  3. On the UFGS Management CCR page, fill out the form and complete the Security Question
  4. Click Submit

SpecsIntact Editor:

  1. In the SI Editor, select the Help menu and select Submit UFGS CCR for Section
  2. On the UFGS Management CCR page, fill out the form and answer the Security Question
  3. Click Submit

 Method 2: Submit a CCR from the WBDG website

  1. In the SpecsIntact Explorer, select the Tools menu, then select Submit a UFGS CCR
  2. On the Unified Facilities Guide Specifications (UFGS) page, sort the table by selecting the drop-down arrow below Divisions, then select a Division (01 - 49) and click Apply
  3. In the list, locate the Section and click the link
  4. On the UFGS Criteria Change Request (CCR) page, fill out the form and complete the Security Question
  5. Click Submit
