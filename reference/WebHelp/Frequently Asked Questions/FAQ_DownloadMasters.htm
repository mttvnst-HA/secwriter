FAQs, Troubleshooting, and Technical Notes

How Do I Download Masters to use with SpecsIntact?

The UFGS Master is released quarterly on the fourth Thursday of the month in February, May, August, and November. SpecsIntact automatically checks to see when a new Unified Facilities Guide Specifications (UFGS) Master is available. When a new version is available, the Current UFGS window will appear, which you can choose to Download or Ignore. If you choose to download, SpecsIntact will download the latest version, then you will be prompted to restore the updated Master.

When prompted that a new UFGS Master is available, follow the prompts to download and restore the Master. However, there are times when you may need to manually download the UFGS Master.

Manually Update the UFGS Master

These steps will help you quickly navigate to the Whole Building Design Guide (WBDG) website's UFGS web page.

  1. In the SpecsIntact Explorer, select the Help menu and select Unified Facilities Guide Specifications (UFGS)
  2. On the WBDG Unified Facilities Guide Specifications (UFGS) page, scroll down to the list and locate the UFGS Master, then click the ZIP link

  1. When the download is complete, open SpecsIntact, then perform one of the following:
    1. Within the Available Projects panel, right-click and select Backup and Restore, then select the Restore tab
    2. Select the File menu and select Backup and Restore, then select the Restore tab
  2. Below Restore from (Source), perform one of the following:
    1. Use the existing location
    2. Click the Change Destination button to browse and select the Downloads folder, then click Select Folder
  3. In the File pane, select the UFGS_M.zip file, then click OK
  4. On the Overwrite Master window, click Yes
  5. On the UFGS Restored window, click OK
