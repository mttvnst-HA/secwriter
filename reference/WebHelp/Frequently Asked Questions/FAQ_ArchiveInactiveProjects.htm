How do i archive inactive projects?

To optimize SpecsIntact's performance, especially when connecting to network servers through a VPN connection, it is recommended to archive inactive projects by setting up a dedicated Working Directory.

Advantages of Archiving Inactive Projects

  • Reduces the number of projects that need to be loaded during startup
  • Reduces the time to locate active projects
  • Allows you to easily show or hide inactive projects when needed

The steps below will help you configure and manage your Working Directories.

Step 1: Creating and connecting a new 'Archive' Working directory

In the examples below, the 'X:' is a placeholder. This would be replaced by the drive letter associated with your Working Directories.

  1. In the SpecsIntact Explorer, select the Setup menu, then select Working Directories
  2. In the Working Directories window, select the Add button
  3. Browse to X:\SpecsIntact
  4. Select New Folder to create a new folder named SI Archives
  5. Once the folder has been created, make sure it is highlighted, then click Select Folder
  6. In the Working Directories window, click OK

Step 2: Relocating Inactive Projects

Option 1: SpecsIntact - Single Job or Master:

  1. In the SpecsIntact Explorer, right-click on the Job or Master and select Properties
  2. In the Properties window, next to the Path field, select the drop-down arrow, then select the SI Archives Working Directory 
  3. Click OK

Repeat this for each project you wish to move to the SI Archives Working Directory.

Option 2: Windows File Explorer - Multiple Jobs:

  1. Close SpecsIntact
  2. Open two instances of Windows File Explorer
  3. In the first window, navigate to the default Working Directory's Jobs or Masters folder (e.g., X:\SpecsIntact\Projects\Jobs)
  4. In the second window, navigate to the SI Archives Working Directory's Jobs or Masters folder (i.e. X:\SpecsIntact\SI Archives\Jobs)
  5. Highlight and copy the Jobs from the default Working Directory's Jobs folder
  6. Paste the Jobs into the SI Archives' Jobs or Masters folder
  7. In the SpecsIntact Explorer, perform one of the following:
    1. Click the Working Directory button on the Toolbar
    2. Select the Setup menu and select Working Directories
  8. To hide the Jobs, uncheck the SI Archives Working Directory
  9. Click OK

Step 3: Show or Hide Archived Jobs:

  1. In the SpecsIntact Explorer, perform one of the following:
    1. Click the Working Directory button on the Toolbar
    2. Select the Setup menu and select Working Directories
  2. Select or deselect to show or hide the SI Archives Working Directory 
  3. Click OK 

After this is complete, each team member will need to connect to the archived Working Directory. From there, they'll simply follow Step 3 to manage the visibility of the archived projects.
