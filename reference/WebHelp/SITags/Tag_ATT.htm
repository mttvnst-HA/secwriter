DESCRIPTION

This tag identifies referenced documents within a specific SectionA set of files within the Division of a Master or Job that covers specific aspects of construction. The attachments are listed in the Section Table of Contents during the Process Print/Publish process.
   
SOURCE

Tagsbar button, Insert menu > Tags, or by using the keyboard shortcut F4.
   
RULES

None
   
CHARACTER LIMITATIONS

None

The attachment feature does not automatically attach files to the specifications. It only lists the files within the corresponding Section Table of Contents. To include the referenced attachments (.pdf files) in the final printed Job, manually insert them using Adobe Acrobat or similar tools.

How to Use This Feature

To Generate An Attachment List Report for a Job or Master:

  1. From the SpecsIntact Explorer, perform one of the following:
    1. Right-click and select Process and Print/Publish
    2. Click the Print/Publish button on the Toolbar
    3. Select the File menu and select Process and Print/Publish
  2. In the Processing for Job or Master window, select the desired option on each tab, then select the Reports tab
  3. Below Reports, select the Attachment List
  4. Click Process & Publish
