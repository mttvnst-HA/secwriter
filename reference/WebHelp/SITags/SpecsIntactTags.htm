SpecsIntact tagsSpecsIntact relies on tags to control content, and formatting, automate processes, and generate reports. These special markers, like <SEC> and </SEC>, define elements and attributes within the specifications. Some tags, like <Page />, function independently. In essence, tags are the building blocks of SpecsIntact documents are used to separate and identify the logical elements of specification files (SectionA set of files within the Division of a Master or Job that covers specific aspects of construction (.sec) files). The tags are listed in alphabetical order with a brief description of each.
