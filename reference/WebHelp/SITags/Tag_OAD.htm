DESCRIPTION

This tag identifies the Reference Standard's Sponsoring Organization address used only in the Sources for Reference Publications Section.
   
SOURCE

Tagsbar button, Insert menu > Tags, or by using the keyboard shortcut F4.
   
RULES

Can only contain text -- Organization Address but not the Organization Name.
   
CHARACTER LIMITATIONS

None

The Organization Address tag is used to encompass the Organization Address for a Reference and is used in the 01 42 00 Sources for Reference Publications Section only.
