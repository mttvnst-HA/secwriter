TAGS

<REF> </REF>
   
DESCRIPTION

This tag identifies a Reference Standard. The Organization Name and acronym, Reference Identifier, issue date and title.
   
SOURCE

Tagsbar button, Insert menu > Tags, or by using the keyboard shortcut F4.
   
RULES

Can only contain ORG, RID, NTE, and RTL tagsSpecsIntact relies on tags to control content, and formatting, automate processes, and generate reports. These special markers, like <SEC> and </SEC>, define elements and attributes within the specifications. Some tags, like <Page />, function independently. In essence, tags are the building blocks of SpecsIntact documents.  In 01 42 00 Sources for Reference Publications SectionA set of files within the Division of a Master or Job that covers specific aspects of construction only, the REF may contain OAD tags.
   
CHARACTER LIMITATIONS

None

The Reference tag is used to encompass a Reference. The Reference Wizard simplifies the process of inserting References within a Reference Article. When inserting a Reference, the Reference Organization (ORG), Reference Identifier (RID), and Reference Title (RTL) are automatically generated.
