TAGS

<RID> </RID>
   
DESCRIPTION

This tag identifies the Reference Identifier's acronym and ID. The RID tags appear as light magenta when viewing colors.
   
SOURCE

Tagsbar button, Insert menu > Tags, or by using the keyboard shortcut F4.
   
RULES

Can only contain text and must be surrounded by a Reference tag within the Reference ArticleAn Article within Part 1 that contains a list of the Publishing Organizations and the titles of all technical references used in the section text. The RID must appear at least once within the body of the Section, other than in 1.x REFERENCES, contained within TXT, LST, ITM, or TAB tags.
   
CHARACTER LIMITATIONS

Thirty (30) Characters

The Reference Identifier tag is used to encompass the reference acronym and number. Failure to observe the rules will result in inaccurate Quality Assurance Reports and Reconciliation of the 01 42 00 Sources for Reference Publication Section.
