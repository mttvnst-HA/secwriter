TAGS

<PRT> </PRT>
   
DESCRIPTION

This tag identifies the Parts within a Section such as PART 1, PART 2, and PART 3.
   
SOURCE

Tagsbar button, Insert menu > Tags, or by using the keyboard shortcut F4.
   
RULES

Can only contain TTL, SPT, NTE, LST, and ITM tags.
.,  
CHARACTER LIMITATIONS

None

The Part tag is used to surround the Parts within a Section. The Construction Specification Institute (CSI) standard is that all Section files have only three parts. The only exception to this standard is the Administrative Documents located within DivisionEach Master is made up of Divisions containing groups of Sections that cover specific construction areas. Division Names and Titles are in accordance with CSI MasterFormat™ 00. Titles for Parts are handled differently than Articles, Paragraphs, and Subparagraphs. Parts are enclosed within TTL tags and begin with PART followed by the part number, three spaces, and title.

To learn more about Section formatting, refer to the Section Format topic.
