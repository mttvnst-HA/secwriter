TAGS

<PGE/>
   
DESCRIPTION

This entity tag identifies a hard page break represented by a solid line. 
   
SOURCE

Insert menu > Tags or by using the keyboard shortcut Ctrl+Enter.
   
RULES

None -- Empty tag that contains no data; one of the few tags that does not have an end tag. The SI Editor prohibits the insertion of this tag in locations where it would not be appropriate (e.g., Submittals, References, Section or Paragraph Titles, and other specialized content). 
   
CHARACTER LIMITATIONS

None

Exercise caution when using hard page breaks. Factors such as Reference and Submittal Reconciliation, English and Metric Units, and renumbering can significantly alter page breaks. The SI Editor's Print Draft may differ considerably from the final page breaks when processed through the SpecsIntact Explorer's Process and Print/Publish. 

 The visual distinction between hard and soft page breaks is noted in their appearance. Hard page breaks are represented by a solid line, and the dotted and dashed lines signify soft page breaks.
