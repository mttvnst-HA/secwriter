TAGS

<NPR> </NPR>
   
DESCRIPTION

This tag identifies paragraphs within a Note. It is the subset of the Note (NTE) tag.
   
SOURCE

Tagsbar button, Insert menu > Tags, or by using the keyboard shortcut F4.
   
RULES

Can only be enclosed within a Note (NTE) tag and can only contain Text and Section Scope (SCP).
   
CHARACTER LIMITATIONS

None

The Note (NTE) tag is used to encompass Specifier NotesSpecifier Notes <NTE> are paragraphs of information included in the Section written to aid the Engineer, Architect, or Specifier in editing the specification that are used to aid the specification editor in editing the SectionA set of files within the Division of a Master or Job that covers specific aspects of construction.

How To Use This Feature

To View a Specifier Note:

  1. In the Editing Window, perform one of the following:
    1. Click the Toggle Notes View button on the Toolbar
    2. To view a hidden Note, click the teal triangle to display the note in a popup window
    3. Use the keyboard shortcut Alt+N

To Insert a Note Paragraph in an existing Note:

  1. In the Editing Window, perform one of the following:
    1. Click the Toggle Notes View button on the Toolbar so notes are visible
    2. Use the keyboard shortcut Alt+N
  2. To place a Note Paragraph within an existing Note, perform one of the following:
    1. Place your cursor before the beginning NPR tag and click the NPR button on the Tagsbar
    2. Place your cursor after the ending NPR tag, press the Enter key twice, and click the NPR button on the Tagsbar
