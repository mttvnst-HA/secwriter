Cannot open Exported Web (.HTM) Files in Excel

While attempting to open the Submittal Register or Tailoring Options exported Web (.htm) file in Excel, the following error occurs: 'You are attempting to open a file type (Web Pages and Excel 2003 XML Spreadsheets) that has been blocked by your File Block Settings in the Trust Center.' 

DoD security policies restrict Web (.htm) files from opening directly through Microsoft Excel.

Solution

To ensure the successful opening of Web (.htm) files, make sure you generate them as an Excel spreadsheet, or you can disable the Use Excel to open HTML files in Exported Files folder option within the SpecsIntact Explorer's Setup menu > Options > General tab. This will ensure the automatic opening of web files in the default web browser. 

If you prefer that the Web (.htm) files consistently open as a web page in the default Browser, you can adjust the setting within SpecsIntact. To do this, navigate to the SpecsIntact Explorer's Setup menu > Options > General tab, and deselect the Use Excel to open HTML files in the Exported Files folder option. Once this setting has changed, then SpecsIntact offers the flexibility to temporarily override this behavior by right-clicking on an exported Web (.htm) file (e.g., UFGS4288.htm) and selecting Open in Microsoft Excel. This allows you to analyze, edit, and save the Web (.htm) file as an Excel (.xlsx) file.

Microsoft Excel (.xlsx) files automatically open directly in the Microsoft Excel application.
