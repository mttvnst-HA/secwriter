SpecsIntact Appears To Be Unresponsive

A common cause of SpecsIntact appearing unresponsive is an incorrect monitor configuration. This often happens when a user leaves their system running, and the monitor setup changes upon returning. In reality, the SpecsIntact window opens on an undetected 'ghost monitor', making it invisible to the user.

Solution

Reset Settings

To reset SpecsIntact window sizes, positions, and other settings, perform the following:

  1. In the SpecsIntact Explorer, select the Setup menu, then select Reset Settings
  2. On the Reset Settings window, check Window sizes and Other settings
  3. Click OK

 You will be able to use the selected function once the settings have been restored to default.
