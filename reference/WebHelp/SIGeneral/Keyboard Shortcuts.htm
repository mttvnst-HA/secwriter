Alternative Keyboard Shortcuts

Alternative keyboard shortcuts allow you to easily navigate through menus and functions within tabs and windows, using the keyboard's Alt Key + Underlined Letter.  A quick press of the keyboard Alt key activates the underlined shortcut letters.  Once a menu or function is active, you can use the keyboard arrow keys to move left and right from menu to menu, whereas up or down will open a menu to choose different menu items.

For example, the File menu has the letter F underlined, so pressing Alt+F opens the File menu.  This technique also works within other windows, like the File menu > Process and Print/Publish.
