The initial local installation of SpecsIntact itself is very light, requiring only about 50 MB of disk space. This minimal footprint means it won't take up much room on your hard drive.

For optimal performance, ensure your Windows system meets the Microsoft Windows requirements.

However, it's crucial to understand that you'll need significant additional disk space for your projects. This includes:

  • Jobs: These are your specific project files, and their size will vary greatly depending on the complexity and number of specifications they contain.
  • Masters: These are your organization's Master specification documents, which can also grow in size as you develop and refine them over time.

The more projects that are created and stored require more disk space. It's wise to anticipate this growth and ensure you have ample free space available.

Optimal Performance Considerations

Beyond disk space, the overall performance of SpecsIntact is closely tied to your computer's operating system. For the best experience, ensure your Windows system meets or exceeds the recommended specifications for your version of Microsoft Windows. This includes factors like:

  • Processor Speed: A faster processor will allow SpecsIntact to open, process, and save files more quickly.
  • RAM (Random Access Memory): Sufficient RAM is critical for smooth multitasking and handling larger specification files.
  • Overall System Health: A well-maintained Windows installation, free from excessive background processes or disk fragmentation, will always contribute to better application performance.

By ensuring your system meets these general Windows requirements, you'll provide SpecsIntact with the optimal environment to run efficiently and reliably.

Optional Software Applications

Adobe Acrobat

Optimal performance for PDF generation is achieved through the use of the integrated SpecsIntact PDF printer. Full compatibility is also extended to Adobe Acrobat. However, it is important to note that third-party PDF applications beyond those specified are not officially supported, and their functionality within SpecsIntact is restricted.

Microsoft Word

SpecsIntact provides a valuable feature for users who need to share their specification documents in a widely accessible format by providing the ability to publish Sections directly to Microsoft Word (.docx) format. This functionality allows the sharing of specifications for collaboration and review, or sharing the final document when requested. Once a SpecsIntact Section is converted to Word, any subsequent editing or changes made in the Word document cannot be imported back into SpecsIntact.

Microsoft Excel

SpecsIntact provides specific features for interacting with spreadsheet files, particularly Microsoft Excel. The primary interaction with Excel is for extracting structured data from SpecsIntact for external processing of the Submittal Register and Tailoring Options List.
