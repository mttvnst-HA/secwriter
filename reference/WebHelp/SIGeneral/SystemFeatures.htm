SpecsIntact is used to extract and edit facility project specifications from Master specifications made up of Divisions and Sections. The system provides Quality AssuranceA systematic process insuring the specification meets the specified requirements set by the UFGS Discipline Working Group as documented within the Unified Facilities Guide Specifications (UFGS) Format Standard (UFS 1-300-02) reports and automated features that reduce the staff hours required to complete project specifications. The Quality Assurance reports verify the accuracy of technical References, Submittal requirements, tests, and other requirements like Section ReferencesA reference to another section included in the specification and Bracketed OptionsText presented with bracketed choices, allowing users to select the desired option.

Automated Features

The automated features will generate a Table of Contents for Projects and Sections, customize the Submittal and Reference Sections, and hide Specifier NotesSpecifier Notes <NTE> are paragraphs of information included in the Section written to aid the Engineer, Architect, or Specifier in editing the specification from the printed or published specifications.

Performance Features

Software performance in SpecsIntact has been optimized for a broad range of functions pertinent to network Working Directories, including those facilitated by a Private Network (VPN) connection. These performance enhancements will be most discernible after the initial loading of an existing Job or Master, enabling SpecsIntact to update associated system files. Areas demonstrating significant improvement are as follows:

  • Network Working Directories
  • Startup of Jobs and Masters (following the initial load)
  • Multiple Networked Jobs and Masters
  • Tailoring
  • Executing Revisions
  • Deleting, Renaming, Duplicating, and Backup or Restoring Jobs and Masters
  • and many more

To optimize performance in network Working Directories, the SpecsIntact Explorer prioritizes performance by delaying the display of titles and other Job or Master data until you select the Job or hover your mouse over it.  Although not recommended, you can disable this feature by deselecting the Optimize performance for network Working Directories option from the SpecsIntact Explorer's Setup menu > Options > General tab.

Assistive Technology

SpecsIntact is committed to ensuring universal access to the software so everyone can have the best experience possible. The software fully supports high-contrast themes, keyboard shortcuts, tooltips, and screen readers to improve functional capabilities.

SI Editor Dark Mode and High-Contrast Themes

The SI Editor provides the flexibility to customize the SI Editor's workspace by choosing from a selection of pre-defined themes, including the familiar Classic theme, dark mode themes such as Twilight and Deep Blue, or the high-contrast Midnight theme, each offering distinct visual styles. Alternatively, create a custom theme to personalize the interface that balances foreground and background contrast according to your preferences and needs. The default theme for the SI Editor is Classic.

High-Contrast Windows Themes

Windows provides high-contrast themes to improve accessibility for users with vision limitations. These themes adjust color contrast levels to make text, window borders, and images stand out more. Users can even choose from various themes that will allow them to personalize their experience.

Operating System

Steps
   
Windows 11

Settings > Accessibility  > Contrast theme, select a theme (e.g., Aquatic Desert, Dusk, or Night sky).
   
Windows 10

Settings > Ease of Access > High Contrast > select a theme > High Contrast Black or High Contrast White.
   

Keyboard Shortcuts and Navigation

SpecsIntact prioritizes accessibility by offering comprehensive keyboard navigation. This allows users who prefer or need to avoid using a mouse to navigate the application seamlessly using keyboard shortcuts, control, and navigation keys.

  • Keyboard Shortcuts: Keyboard shortcuts are used throughout the SpecsIntact Explorer and SI Editor as an alternative way to quickly access menus and functions. These shortcuts are displayed directly within each application menu and offer quick access to frequently used functions.
  • Keyboard Navigation: Keyboard navigation uses the Alt, tab, Shift+tab, arrows, and spacebar to navigate application windows. These keyboard command keys let you open menus, activate commands, and make selections.

Key

 Function
   
Alt

Pressing the Alt key brings up menus, while a quick press of the keyboard Alt+ underlined letter in the menu activates that specific function.
   
Arrows Use the arrow keys to move around within windows to switch between open tabs (e.g., left, right, up, or down).

Shift+Tab Moves backward to the previous option or field within the active window.

Screen Reader Compatible

SpecsIntact is committed to ensuring the software is fully compatible with essential assistive screen reader technology. Screen readers are a type of assistive technology that translates visual information into audio output.

Tooltips

Tooltips (also called hints or screentips) are small informational boxes of information that pop-up when you hover your mouse over a specific element on your screen. These helpful visual cues are part of a graphical user interface (GUI) and give you quick access to relevant details without needing to click or open another window or document.

Touchscreen Scroll and Zoom Capabilities

Use the TouchscreenA touchscreen display will detect and respond to user touch gestures so they can interact with the device directly on the screen instead of using a mouse or keyboard to navigate by using your finger to scroll vertically and horizontally and zoom in and out.

  • To scroll vertically, swipe up and down.
  • To scroll horizontally, swipe diagonally from top right to bottom left (and vice versa).
  • To zoom in, place the thumb and finger together on the screen and slowly move them apart while keeping them on the screen.
  • To zoom out, place the thumb and finger together at a slight distance and slowly pinch together while keeping them on the screen.
